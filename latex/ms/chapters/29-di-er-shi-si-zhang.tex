\booksection{Soalan Lazim (Q\& A)}

\textbf{Q1: Selepas buka kunci BL boleh pulih?}\par

\textbf{A:}Boleh kunci semula. Biasanya perlu flash pakej wayar rasmi lengkap, dan guna skrip flash tertentu (seperti Xiaomi\texttt{flash\_all\_lock.\allowbreak bat}) boleh kunci semula. Tetapi perhatikan, selepas kunci semula, sesetengah trip keselamatan yang dicetus oleh buka kunci (seperti Knox Samsung) mungkin tidak boleh balik.

\textbf{Q2: Selepas buka kunci bagaimana Root?}\par

\textbf{A:}Buka kunci BL hanya langkah pertama. Root biasanya perlukan:

\begin{enumerate}
  \item Tetapan Sistem Pilihan set semula Padam semua data (Android).
  \item Melalui Recovery flash Magisk dan pengurus Root lain untuk patch image boot, bagi mendapat kebenaran Root.
\end{enumerate}

\booksection{Deep Understanding of Bootloader}

Bootloader is the first program to run when the phone starts; its task is to initialize hardware and load the operating system kernel. You can think of Bootloader as the phone's “gatekeeper.”

\booksubsection{How BL Lock Works:}

\begin{itemize}
  \item \textbf{Verify signature}: BL lock verifies the digital signature of the boot image; only manufacturer-signed systems can boot.
  \item \textbf{Prevent downgrade}: Prevents users from flashing older system versions to exploit known vulnerabilities.
  \item \textbf{Protect data}: Even if a new system is flashed, user data cannot be accessed without the original account password.
\end{itemize}

\booksection{Flashing Introduction}

Flashing refers to installing a new operating system on the phone. Common flashing types:

\begin{itemize}
  \item \textbf{Flash official ROM}: Install the official system, used for rescuing bricked phones or downgrading.
  \item \textbf{Flash third-party Recovery}: Such as TWRP, used for backup and recovery, flashing third-party ROMs.
  \item \textbf{Flash third-party ROM}: Such as LineageOS, Pixel Experience, etc., to experience different systems.
\end{itemize}

\booksection{VI. FAQ (Q\& A)}

\textbf{Q1: Can BL Unlock Be Reversed?}\par

\textbf{A:}Yes, it can be relocked. Usually requires flashing the official complete firmware package and using a specific flashing script (such as Xiaomi's\texttt{flash\_all\_lock.\allowbreak bat}) to relock. However, note that after relocking, some security fuses triggered by unlocking (such as Samsung's Knox) may be irreversible.

\textbf{Q2: How to Root After Unlocking?}\par

\textbf{A:}Unlocking the BL is just the first step. Rooting usually requires:

\begin{enumerate}
  \item Flashing a custom Recovery (such as TWRP).
  \item Flashing Magisk or other Root managers through Recovery to patch the boot image and gain Root access.
\end{enumerate}

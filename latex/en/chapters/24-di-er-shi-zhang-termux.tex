\booksection{Chapter 20 Appendix: Termux—A Portable Linux Terminal Environment on Android Devices}

\chapterintro{If you feel Developer Mode isn't “hardcore” enough and want to experience a complete Linux command line on your phone, then Termux is for you. It requires no root permission, yet can turn an ordinary Android phone into a portable Linux workstation—a powerful tool for advanced users to explore mobile development and operations.}

\booksubsection{What Is Termux}

Termux is an open-source terminal emulator and Linux environment application designed specifically for Android devices. It provides a complete Linux shell experience on your phone without requiring root permission. As a lightweight application (installation package only about 30MB), Termux supports a rich software ecosystem through the APT package management system, allowing users to run tools like Python, Node.js, Git, SSH on mobile devices, and even set up servers or perform penetration testing.

Termux's core advantages lie in its lightweight nature and high extensibility, suitable for development, learning, and system administration scenarios. It combines standard software packages with precise terminal emulation in an open-source solution.

\booksubsection{Core Features and Characteristics}

\subsubsection*{Complete Linux Environment}

Termux\textbf{Only Bash is Built-in}is the only built-in shell. If you want to use Zsh, fish, or other shells, you need to install them manually via the package manager, for example:\texttt{pkg install zsh}or\texttt{pkg install fish}. Termux also supports editors like Vim, Nano, and Emacs, providing a near-native command-line experience. Users can install 2000+ packages via “pkg install,” including GCC, OpenSSH, SQLMap, and other development and security tools.

\subsubsection*{Powerful Package Management}

Uses the APT package manager (similar to Debian and Ubuntu), can install thousands of Linux software packages, covering development tools, network tools, and more. Supports multiple programming language environments including Python, Ruby, Node.js, Go, Rust, and Swift.

\subsubsection*{Security and Network Features}

\begin{itemize}
  \item \textbf{SSH remote connection}: Supports SSH client and server features—connect to other devices remotely or turn your phone into an SSH host.
  \item \textbf{Encryption tools}: Provides encryption tools like OpenSSL, supports data encryption and secure communication.
  \item \textbf{Server setup}: Can configure Nginx or Apache to set up a static web server.
\end{itemize}

\subsubsection*{System Integration and Extension}

\begin{itemize}
  \item Access phone storage permissions for local file management.
  \item Call Android hardware features like sensors and cameras through the Termux:API plugin.
  \item Supports Bluetooth keyboard and external display connection, with full mouse support.
\end{itemize}

\begin{tcbwarn}{Important Note}
Termux and its plugins must be installed from the same source, because they share the same sharedUserId. Mixing installations from different sources (such as F-Droid and GitHub) will result in installation errors.

\end{tcbwarn}

\booksubsection{Installation and Configuration Guide}

\subsubsection*{Installation Steps}

\begin{enumerate}
  \item \textbf{Download the app}: Download and install Termux from official channels (F-Droid or GitHub), no root permission required.
  \item \textbf{Initialize the system}: Wait for "Installing bootstrap packages" to complete after first launch.
  \item \textbf{Get storage permission}: Execute\texttt{termux-\allowbreak setup-\allowbreak storage}to get phone file system permission.
  \item \textbf{Update package sources}: Execute\texttt{: Use the}to update the package list.
\end{enumerate}

\subsubsection*{Basic Optimization}

\begin{itemize}
  \item \textbf{Change mirror source}: Use the\texttt{Enter}command to change the mirror source through a graphical interface (Tsinghua University mirror recommended).
  \item \textbf{Shortcut settings}: Volume down key simulates Ctrl, volume up key simulates Esc, improving input efficiency.
  \item \textbf{Interface beautification}: Install Zsh + Oh My Zsh, configure themes and plugins.
\end{itemize}

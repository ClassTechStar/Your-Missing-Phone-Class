\booksection{官方支持乃首選：}

\begin{itemize}
  \item \textbf{蘋果用戶}：apple.com/cn 與 iCloud.com。
  \item \textbf{安卓用戶}：手機品牌之官網皆有"服務與支持"板塊。
  \item \textbf{通用工具}：蘋果用iTunes，華爲用華爲手機助手，小米用小米換機。
\end{itemize}

\booksection{實用網站與博主：}

\begin{itemize}
  \item \textbf{查技巧}：於B站搜索"【君之手機型號】技巧"。
  \item \textbf{觀測評}：多觀幾個不同博主之測評視頻。
  \item \textbf{學拍照}：關注手機攝影教程博主。
\end{itemize}

\booksection{安全自查一句話清單：}

\begin{enumerate}
  \item 鎖屏密碼設矣乎？
  \item "查找我的手機"開矣乎？
  \item 重要賬號之雙重認證開矣乎？
  \item 定期給照片、微信聊天記錄做備份矣乎？
  \item 記防騙口訣：不輕信、不泄露、不轉賬、不貪心、不急躁。
\end{enumerate}

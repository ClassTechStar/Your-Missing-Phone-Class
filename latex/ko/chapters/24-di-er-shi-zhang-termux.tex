\booksection{제20장 부록: Termux — Android 기기의 휴대용 Linux 터미널 환경}

\chapterintro{개발자 모드만으로는 아직 “하드코어”하지 않다고 느끼고, 스마트폰에서 완전한 Linux 명령줄을 경험하고 싶다면, Termux가 바로 그 해답입니다. Root 권한 없이도 일반 안드로이드 스마트폰을 휴대용 Linux 워크스테이션으로 바꿀 수 있어, 고급 사용자가 모바일 개발 및 운영을 탐구하는 훌륭한 도구입니다.}

\booksubsection{하나, Termux란 무엇인가}

Termux는 Android 기기 전용으로 설계된 오픈 소스 터미널 에뮬레이터 및 Linux 환경 응용 프로그램으로, Root 권한 없이도 스마트폰에서 완전한 Linux Shell 경험을 제공합니다. 경량 응용 프로그램(약 30MB 설치 패키지)으로서, APT 패키지 관리 시스템을 통해 풍부한 소프트웨어 생태계를 지원하며, 사용자가 모바일 기기에서 Python, Node.js, Git, SSH 등의 도구를 실행하거나, 서버를 구축하거나, 침투 테스트를 수행할 수 있습니다.Termux의 핵심 이점은 경량화와 높은 확장성으로, 개발, 학습 및 시스템 관리 등 다양한 시나리오에 적합합니다. 표준 소프트웨어 패키지와 정밀한 터미널 에뮬레이션을 하나의 오픈 소스 솔루션으로 결합했습니다.둘, 핵심 기능과 특성완전한 Linux 환경Termux는\textbf{Bash Shell 하나만 내장}되어 있습니다. Zsh나 fish 등 다른 Shell을 사용하려면 패키지 관리자를 통해 수동으로 설치해야 합니다. 예:\texttt{pkg install zsh}또는\texttt{pkg install fish}. 동시에 Termux는 Vim, Nano, Emacs 등의 편집기를 지원하여 거의 네이티브에 가까운 명령줄 경험을 제공합니다. 사용자는 “pkg install”로 2000개 이상의 소프트웨어 패키지를 설치할 수 있으며, GCC, OpenSSH, SQLMap 등 개발 및 보안 도구가 포함됩니다.강력한 패키지 관리APT 패키지 관리자(Debian 및 Ubuntu와 유사)를 사용하여, 개발 도구, 네트워크 도구 등을 포함하여 수천 가지 Linux 소프트웨어 패키지를 설치할 수 있습니다. Python, Ruby, Node.js, Go, Rust, Swift 등 다양한 프로그래밍 언어 환경을 지원합니다.보안 및 네트워크 기능\textbf{SSH 원격 연결}: SSH 클라이언트 및 서버 기능을 지원하여, 다른 기기에 원격으로 연결하거나 스마트폰을 SSH 호스트로 만들 수 있습니다.\textbf{암호화 도구}: OpenSSL 등 암호화 도구를 제공하여, 데이터 암호화 및 보안 통신을 지원합니다.\textbf{서버 구축}: Nginx 또는 Apache를 구성하여 정적 웹 페이저 서버를 구축할 수 있습니다.시스템 통합 및 확장스마트폰 저장소 권한에 접근하여 로컬 파일 관리를 구현합니다.Termux:API 플러그인을 통해 센서, 카메라 등 Android 하드웨어 기능을 호출합니다.블루투스 키보드 및 외부 모니터 연결을 지원하며, 완전한 마우스 지원을 제공합니다.셋, 플러그인 생태계Termux의 핵심 응용 프로그램은 여러 선택적 플러그인 응용 프로그램을 통해 확장하여 추가 기능과 통합을 제공할 수 있습니다:플러그인 이름기능 설명Termux:API명령줄 프로그램에 Android API 기능을 노출Termux: Boot기기 부팅 시 스크립트 실행 허용Termux: Float플로팅 터미널 창 제공Termux: Styling터미널에 색상 테마 및 글꼴 사용자 정의 활성화Termux: TaskerTermux 스크립트를 Tasker 자동화 앱과 통합Termux: Widget홈 화면 위젯에서 스크립트 실행 허용중요한 알림Termux와 해당 플러그인은 동일한 sharedUserId를 공유하므로 같은 출처에서 설치해야 합니다. 서로 다른 출처(예: F-Droid와 GitHub)의 설치를 혼합하면 설치 오류가 발생합니다.넷, 설치 및 구성 가이드설치 단계\textbf{응용 프로그램 다운로드}: 공식 채널(F-Droid 또는 GitHub)에서 Termux를 다운로드하여 설치하며, Root 권한이 필요 없습니다.\textbf{시스템 초기화}: 처음 시작한 후 “Installing bootstrap packages”가 완료될 때까지 기다립니다.\textbf{저장소 권한 획득}:\texttt{termux-\allowbreak setup-\allowbreak storage}를 실행하여 스마트폰 파일 시스템 권한을 얻습니다.\textbf{소프트웨어 소스 업데이트}:\texttt{pkg update \&\& pkg upgrade}를 실행하여 소프트웨어 패키지 목록을 업데이트합니다.기초최적화\textbf{미러 소스 변경}:\texttt{termux-\allowbreak change-\allowbreak repo}명령을 사용하여 그래픽 인터페이스로 미러 소스를 변경(칭화대학교 미러 소스 권장).\textbf{단축키 설정}: 볼륨 감소 키를 Ctrl로, 볼륨 증가 키를 Esc로 시뮬레이션하여 입력 효율을 높입니다.\textbf{인터페이스 미화}: Zsh + Oh My Zsh를 설치하고, 테마와 플러그인을 구성합니다.다섯, 일반적인 응용 시나리오모바일 개발 테스트스마트폰에서 완전한 개발 환경을 구축하고, Python 스크립트를 작성 및 실행하고, GCC로 C 프로그램을 컴파일하며, Git으로 코드 저장소를 관리하고, SSH와 결합하여 원격 서버와 동기화합니다.서버 운영 및 유지 보수SSH로 서버를 원격 관리하고, 시스템 유지 보수, 로그 분석 등의 작업을 수행하며, 언제 어디서나 서버 문제를 처리합니다.Linux 학습실제 Linux 환경을 제공하여, 명령줄과 시스템 관리를 배우기에 이상적인 플랫폼입니다. Shell 스크립트 작성, Linux 파일 권한 관리(예:\texttt{chmod 755}로 rwxr-xr-x 권한 비트 설정,\texttt{chown user: group}으로 파일 소유권 변경,\texttt{ls -\allowbreak l}로 owner/group/other 3그룹 9비트 권한 보기) 등 기본 명령을 연습할 수 있습니다. 이것은 Unix/Linux의 고전적인 “3그룹 9비트” 권한 모델(owner / group / other × 읽기 / 쓰기 / 실행)로, Windows NTFS의 ACL 접근 제어 목록과는 완전히 다른 두 시스템입니다.네트워크보안테스트Nmap, SQLMap, Hydra, Metasploit 등 보안 도구를 설치하여 네트워크 스캔 및 침투 테스트를 수행합니다.여섯, 버전 및 호환성Termux의 최신 안정 버전은 v0.118.2로, Android 7 이상 기기에 적용됩니다. 참고할 점은, Termux는 Android 12 이상에서 불안정성이 있을 수 있으므로, 공식 업데이트 로그를 주시하여 최신 호환성 정보를 얻는 것이 좋습니다.요약Termux는 강력한 Linux 터미널 경험을 Android 기기로 가져와, 스마트폰을 휴대용 개발 및 학습 도구로 만듭니다. 개발자, 시스템 관리자, 기술 애호가 모두 Termux를 활용하여 모바일 기기에서 완전한 명령줄 경험을 즐기고, “주머니 속의 Linux”라는 이념을 실현할 수 있습니다.직접 해보기: 스마트폰에서 첫 번째 Linux 명령 실행F-Droid에서 Termux를 다운로드하여 설치하고, 처음 시작 시 초기화가 완료될 때까지 기다립니다.\texttt{pkg update \&\& pkg upgrade}를 실행하여 소프트웨어 패키지를 업데이트합니다.설치Python:\texttt{pkg install python}.\texttt{python3 -\allowbreak c “print('Hello from Termux!')”}를 입력하여, 스마트폰에서 코드를 실행하는 즐거움을 느껴보세요.

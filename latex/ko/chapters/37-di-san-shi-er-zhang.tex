\bookchapter{제32장: 휴대폰 보안 응급 처치 매뉴얼}

\chapterintro{이 장은 “비상 시나리오”입니다. 평생 쓰지 않기를 바라지만, 정말로 휴대폰을 잃어버리거나 도난당하거나 사기를 당했을 때 이 매뉴얼이 손실을 최소화해 줍니다. 지진, 폭우 같은 재해가 닥쳤을 때도 휴대폰은 경보 수신, 위치 구조, 연락 유지의 도구입니다. 지금 한 번 정독한 뒤 핵심 단계를 스크린샷해 저장하거나 인쇄해 집에 두세요. 사고가 났을 때 휴대폰이 손에 없을 수 있고, 재해 시에는 배터리가 없거나 신호가 없을 수 있기 때문입니다.}

\booksection{장면 0: 지진 / 극단적 날씨 — 휴대폰이 목숨을 구하는 법}

지키는 것은 신체 안전이지 계정 자금이 아닙니다. 경보 설정은 13장 “날씨 경보, 자연재해 경보, 지진 경보”를 참고하세요. 여기에서는 경보가 울린 뒤의 행동만 다룹니다.

\textbf{지진 경보가 울렸다: 먼저 엎드리고, 영상 찍느라 정신 팔지 마세요}\par

\begin{enumerate}
  \item 가까운 곳 대피: 엎드리기, 보호하기, 붙잡기(책상 아래, 내력벽 모서리, 견고한 가구 옆). 머리와 목을 보호하고 유리, 외벽, 샹들리에서 멀리하세요.
  \item 무작정 뛰어내리지 마세요: 본진은 보통 수 초\textasciitilde{}수십 초뿐이고 계단실이 더 위험할 수 있습니다. 엘리베이터는 절대 쓰지 마세요.
  \item 진동이 멈춘 뒤 질서 있게 대피: 계단으로 이동하고 여진과 낙하물에 주의하세요. 전봇대, 광고판, 위험 건물에서 떨어진 넓은 곳으로 가세요.
  \item 휴대폰은 요긴하게: 긴 통화보다 긴급 연락처에 짧은 메시지("나는 XX에 있어요, 안전/다쳤어요, 도움이 필요해요")를 보내는 것이 배터리를 아낍니다. 문자/WeChat이 가능하면 텍스트를 우선하세요.
  \item 신호가 없을 때: 7장 위성 SOS / 위성 메시지(기종 지원 시)를 참고하세요. 또는 높은 곳, 넓은 곳에서 다시 시도하세요. 일부 장면에서는 무인터넷 블루투스 인터콤도 도움이 됩니다.
  \item 불필요한 기능 끄기: 비상 시 비행기 모드를 켰다가 예약 종료, 블루투스 스캔 끄기, 밝기 낮추기를 하면 몇 시간 더 버틸 수 있습니다. 마지막 배터리는 안부와 구조 요청에 남기세요.
\end{enumerate}

\begin{tcbwarn}{폭우 / 태풍 / 산사태: 경보 단계부터 행동하세요}
\begin{itemize}
  \item 적색 경보를 보면: 외출을 최소화하고 지하 공간, 하부 통과 교량, 하천, 비탈면에서 멀리하세요.
  \item 야외에서 고립됐다면: 견고한 건물 높은 곳으로 이동하세요. 억지로 물을 건너지 마세요(침수 구간에는 맨홀 빠짐과 감전 위험이 있습니다). 119/110에 신고할 때 랜드마크와 수위를 명확히 말하세요.
  \item 출발 전: 날씨 앱과 현지 경보 공식 계정으로 위험을 확인하세요. 장거리 자가용은 산간·임야·절벽 구간을 피해 주세요.
  \item 가족 간 약속: "연락이 끊기면 마지막 WeChat/문자 위치를 기준으로 한다"고 정해 두세요. 각자 미친 듯이 전화를 걸어 배터리를 소진하지 마세요.
\end{itemize}

\end{tcbwarn}

\begin{tcbpractice}{평소에 해둘 4가지}
\begin{enumerate}
  \item 시스템 지진 경보 / 정규 경보 앱을 켜고, 무음 돌파를 허용하세요.
  \item 연락처 상단에 "긴급 연락처" 2\textasciitilde{}3명을 고정하고, 잠금 화면에 표시되도록 하세요(iOS/안드로이드 의료 정보 카드 또는 잠금 화면 정보).
  \item 집과 가방에 보조 배터리를 준비하세요. 장거리 이동 전 충전하고 케이블을 챙기세요.
  \item "연락처 없이도 걸 수 있는" 번호(가족 휴대폰)를 최소 하나는 외우고, 종이에 적어 지갑에 넣어 두세요.
\end{enumerate}

\end{tcbpractice}

\booksection{장면 1: 휴대폰을 잃어버렸다/도난당했다 — 골든타임 30분}

휴대폰 분실 후 첫 30분은 “골든타임”입니다. 제대로 처리하면 재산과 프라이버시를 지킬 수 있습니다. 아래 순서대로 한 단계도 건너뛰지 마세요.

\textbf{분실 후 30분 표준 절차}\par

\begin{enumerate}
  \item 남의 휴대폰으로 내 번호에 전화(1분 차): 그냥 근처에 떨어뜨렸을 수도 있고, 착한 사람이 받아 주면 되찾을 수 있습니다.
  \item 원격 잠금(2\textasciitilde{}5분 차): 남의 휴대폰이나 PC로 검색 서비스에 로그인하세요. iPhone: iCloud.com > iPhone 찾기 > 내 기기 선택 > 분실로 표시
  \item 안드로이드 브랜드별: 화웨이 cloud.huawei.com / 샤오미 i.mi.com / OPPO cloud.oppo.com 등
  \item SIM 카드 정지(5\textasciitilde{}10분 차): 통신사 고객센터(China Mobile 10086 / China Unicom 10010 / China Telecom 10000)에 전화해 휴대폰 분실로 SIM 서비스 중지를 요청하세요. 이 단계가 가장 중요합니다. 사기꾼이 당신의 SIM 카드를 손에 넣으면 인증번호를 받아 모든 비밀번호를 재설정할 수 있습니다.
  \item 결제 계정 동결(10\textasciitilde{}20분 차): Alipay: 95188 정지 신고 또는 다른 휴대폰에서 Alipay 로그인 > 내 정보 > 설정 > 보안 센터 > 긴급 동결
  \item WeChat: 110 신고 후 WeChat 고객센터에 연락하거나 WeChat 보안 센터 > 계정 동결
  \item 은행 앱: 은행카드 뒷면의 고객센터에 전화해 인터넷 뱅킹 동결을 요청하세요
  \item 지인에게 알리기(20\textasciitilde{}25분 차): 모멘트에 올리거나 가족이 대신 메시지를 보내 휴대폰 분실을 알리세요. 사기꾼이 당신 행세로 남을 속이지 못하게 하세요.
  \item 신고(25\textasciitilde{}30분 차): 110에 전화하거나 가까운 파출소에 가서 신고하고 접수증을 받으세요. 이후 보험 청구, 은행 분쟁에 모두 필요합니다.
\end{enumerate}

\booksection{장면 2: 사기를 당했다 — 72시간 골든 처리 기간}

사기를 당한 뒤 가장 중요한 것은 침착함입니다. 당황 속에서 잘못된 결정을 하면 2차 손실이 생깁니다. 아래 절차대로 하세요.

\begin{enumerate}
  \item 즉시 모든 송금 중단: 사기꾼이 뭐라고 하든 한 푼도 더 보내지 마세요. "보증금을 한 번 더 보내면 이전 금액을 돌려주겠다"는 고전적인 2차 사기 수법입니다.
  \item 모든 증거 보존: 채팅 기록을 지우지 마세요! 통화 기록을 지우지 마세요! 채팅, 송금 내역, 상대 계정 정보를 스크린샷해 저장하세요. 신고와 자금 회수의 핵심 증거입니다.
  \item 즉시 96110에 전화: 전국 사기 신고 핫라인입니다. 상담원이 긴급 지급 정지를 안내합니다. 송금 후 얼마 안 됐다면(보통 24시간 이내) 은행이 상대 계정을 동결해 자금을 가로챌 수 있습니다.
  \item 110에 신고: 휴대폰, 신분증, 송금 증빙을 챙겨 가까운 파출소에서 진술을 받으세요.
  \item 은행/결제 플랫폼에 연락: 사기 상황을 알리고 관련 계정 동결을 요청하세요. 신용카드 도용이라면 은행에 지불 거절 절차를 요청하세요.
  \item 모든 비밀번호 변경: 안전한 다른 기기에서 Apple ID/브랜드 계정, WeChat, Alipay, 은행 앱의 비밀번호를 바꾸고 2단계 인증을 켜세요.
\end{enumerate}

\booksection{장면 3: 휴대폰에 바이러스/트로이 목마가 걸렸다 — 어떻게?}

휴대폰에 다음과 같은 증상이 있다면 — 이상한 광고 팝업, 수상한 앱 자동 설치, 요금 폭증, 데이터 이상 소비 — 악성 코드 감염 가능성이 높습니다.

\begin{itemize}
  \item 1단계: 안전 모드 진입 — 안드로이드는 전원 버튼을 길게 눌러 끈 뒤 다시 길게 눌러 켜고, 진동 후 볼륨 다운 버튼을 계속 길게 눌러 안전 모드로 들어가세요(왼쪽 아래에 "안전 모드"가 표시됩니다). 안전 모드에서는 모든 타사 앱이 비활성화되어 진단이 쉽습니다.
  \item 2단계: 의심 앱 제거 — 안전 모드에서 설정 > 앱 관리로 들어가 시간순 정렬 후 최근 설치된 모르는 앱을 찾아 제거하세요.
  \item 3단계: 보안 앱으로 스캔 — "Tencent Mobile Manager" 또는 "360 Mobile Guard"를 설치해 전체 스캔을 하세요.
  \item 4단계: 공장 초기화(최후의 수단) — 위 방법이 모두 효과가 없다면 중요한 데이터를 백업한 뒤 공장 초기화하세요. 주의: 공장 초기화는 모든 데이터를 삭제합니다. 사진, 연락처 등 중요한 파일을 반드시 먼저 백업하세요.
  \item iPhone은 사실상 바이러스에 걸리지 않습니다 — iOS의 샌드박스 메커니즘 덕분에 악성 코드가 살아남기 어렵습니다. iPhone에 이상이 있다면 대부분 특정 앱의 버그나 설정 문제이며, 공장 초기화로 99\% 해결됩니다.
\end{itemize}

\booksection{장면 4: 계정을 도난당했다 — 빠르게 되찾기}

\begin{enumerate}
  \item 즉시 비밀번호 변경: 아직 로그인된다면 가장 먼저 비밀번호를 바꾸세요. 새 비밀번호는 이전과 완전히 달라야 합니다.
  \item 다른 기기 내보내기: 계정 보안 설정에서 "로그인 기기 관리"를 찾아 모르는 기기를 모두 로그아웃시키세요.
  \item 로그인 기록 확인: 최근 7일 로그인 기록을 확인하세요. 다른 지역 로그인이 있다면 계정이 실제로 도난당한 것입니다.
  \item 2단계 인증 켜기: 아직 켜지 않았다면 지금 바로 켜세요. 계정 재도난을 막는 가장 효과적인 방법입니다.
  \item 연동 정보 확인: 계정에 묶인 휴대폰 번호, 이메일이 바뀌지 않았는지 확인하세요. 바뀌었다면 계정 이의신청 기능으로 되찾으세요.
  \item 결제 설정 확인: WeChat/Alipay가 도난당했다면 간편 결제, 자동 출금이 조작되지 않았는지, 은행카드가 낯선 계정에 추가되지 않았는지 확인하세요.
\end{enumerate}

\booksection{장면 5: 협박 메시지를 받았다 — 겁먹지 말고, 돈 내지 마세요}

흔한 협박 패턴은 두 가지입니다. (1)“당신의 나체 영상/사진이 있다. 돈을 주지 않으면 연락처 전체에 보내겠다” (2)“당신 휴대폰이 해킹됐다. 돈을 주지 않으면 잠가 버리겠다”. 이런 상황에서는:

\begin{itemize}
  \item 99.9\%는 사기입니다: 손에는 당신의 프라이버시 데이터가 전혀 없습니다. 같은 협박 메시지를 수만 명에게 보내면 겁먹고 돈을 보내는 사람이 있기 마련입니다.
  \item 답장하지 말고, 돈 보내지 마세요: 답장하면 "이 번호 사람이 있다"는 걸 알려 주는 셈이고, "협박 가능 목표"로 표시되어 이후 방해가 더 커집니다.
  \item 스크린샷으로 증거를 남기고 상대를 차단하세요.
  \item 비밀번호 변경: 걱정된다면 주요 계정의 비밀번호를 바꿔 안심하세요.
  \item 정말로 프라이버시 유출 위험이 있다면: 신고하세요. 경찰은 이런 사건을 처리한 경험이 있습니다.
\end{itemize}

\booksection{장면 6: AI 얼굴 합성 / AI 목소리 합성 사기 — 보이는 게 다가 아니다}

2024년부터 AI 얼굴 합성과 AI 음성 합성 기술로 사기꾼이 영상 통화에서 당신의 가족, 상사, 친구의 얼굴과 목소리로 “변신”할 수 있게 되었습니다. “엄마, 나 큰일 났어, 빨리 돈 좀 보내줘” — 화면 속 사람의 얼굴과 목소리가 당신 아들과 똑같아 보이지만 가짜입니다. 현재 가장 방어하기 어렵고 위험한 사기 수법 중 하나입니다.

\textbf{1단계: 허점 찾기 — AI 위조의 네 가지 흔한 약점}\par

\begin{itemize}
  \item 눈 깜빡임 비정상: 실제 사람은 분당 15\textasciitilde{}20회 깜빡이는데, AI 얼굴 합성은 깜빡임이 너무 적거나 리듬이 어색합니다.
  \item 입 모양과 오디오 불일치: 입 모양과 들리는 목소리 사이에 0.몇 초의 어긋남이 있습니다.
  \item 얼굴 가장자리 흐림: 얼굴 윤곽, 귀 주변, 머리카락 가장자리에 "털" 같은 흐림이나 반짝임이 생기기 쉽습니다.
  \item 빛 방향 불일치: 얼굴의 하이라이트, 그림자와 배경의 광원 방향이 맞지 않거나, 옆얼굴일 때 이목구비가 "따라 회전"하는 게 어색합니다.
\end{itemize}

\begin{tcbinfo}{2단계: 상대 진위를 확인하는 세 가지 방법}
\begin{itemize}
  \item 특정 동작 요구하기: 고개를 돌리고, 얼굴을 가리고, 손으로 입을 막은 뒤 벌렸다 닫았다 하게 하세요. AI 얼굴 합성은 가림과 큰 각도 회전에서 가장 잘 "들킵니다" — 얼굴이 일그러지거나 동작을 못 따라갑니다.
  \item 상대만 아는 질문하기: 가짜 질문을 하나 지어 보세요. 예: "지난번 우리 강아지 어느 병원에 데려갔지?" — 사기꾼이라면 대답하지 못하거나 얼버무립니다.
  \item 알려진 번호로 되전화: 영상 통화를 끊고 연락처에 저장된 번호로 직접 전화하세요. 사기꾼은 실제 휴대폰 번호를 조종할 수 없어 바로 들킵니다.
\end{itemize}

\end{tcbinfo}

\begin{tcbwarn}{3단계: 사기 확인 후 신고 절차}
\begin{enumerate}
  \item 즉시 송금 중단: 아무리 "급해도" 먼저 멈추세요. "빨리 송금하고 전화 끊지 마"라고 재촉하는 사람은 거의 다 사기꾼입니다.
  \item 모든 증거 보존: 화면 녹화, 스크린샷으로 영상 통화 화면, 채팅 기록, 상대 계정, 송금 증빙을 저장하세요 — 기술 감정의 핵심 자료입니다.
  \item 96110 사기 신고 핫라인에 전화: "AI 얼굴 합성/음성 합성" 사기라고 알리면 상담원이 긴급 지급 정지를 시작합니다.
  \item 110에 신고: 증거를 모두 챙겨 파출소에서 진술하고, AI 위조 기술이 사용됐음을 특히 명시해 경찰이 사건을 정확히 분류할 수 있게 하세요.
  \item 지인에게 알리기: 사기꾼이 당신의 위조 영상으로 다른 사람을 속일 수 있으니 모멘트나 가족 단톡방에 미리 경고하세요.
\end{enumerate}

\end{tcbwarn}

\booksection{장면 7: SIM 스와프 공격(SIM 납치) — 번호를 “도둑맞았다”}

많은 사람이 들어보지 못했지만 피해가 극심한 공격입니다. SIM 스와프(SIM 카드 납치)는 공격자가 당신의 신분 정보를 위조해 대리점에서 새 SIM 카드를 재발급받는 것입니다. 재발급이 성공하면 당신 휴대폰의 신호가 갑자기 사라지고, 공격자 휴대폰에 그 새 카드가 꽂혀 당신의 모든 문자 인증번호를 받게 됩니다 — Alipay, 은행, WeChat까지 모두 열리는 셈입니다.

\begin{tcbinfo}{어떻게 알아차릴까? SIM 스와프의 세 가지 경보 신호}
\begin{itemize}
  \item 휴대폰이 갑자기 "서비스 없음"/"SIM 카드 없음"을 표시하는데, 카드를 건드리지도 않았고 재시동해도 소용없다 — 대개 납치가 일어난 순간입니다.
  \item 통신사에서 "재발급 완료" 또는 "업무 처리 완료" 문자가 왔는데, 본인이 한 적이 없다.
  \item 갑자기 인증번호가 안 오고 다른 문자도 안 온다 — 문자가 공격자의 카드로 납치된 것입니다.
\end{itemize}

\end{tcbinfo}

\begin{tcbwarn}{방어 조치 — SIM 카드도 "잠그기"}
\begin{itemize}
  \item SIM 카드 PIN 설정: 경로 설정 > 전화 > SIM 카드 PIN. 켜면 휴대폰을 재시동하거나 카드를 바꿀 때마다 PIN을 입력해야 카드를 쓸 수 있습니다. 공격자가 카드를 손에 넣어도 쓸 수 없습니다.
  \item 통신사 2차 인증 켜기: China Mobile/Unicom/Telecom 앱에 로그인해 "보안 센터" 또는 "업무 처리 인증"에서 본인 외 재발급 문자 알림과 업무 처리 2차 비밀번호 인증을 켜세요. 남이 당신의 카드를 재발급받으러 가면 직원이 추가 신분 확인을 요구하게 됩니다.
  \item 중요 계정은 문자 인증만 쓰지 마세요: 은행, Apple ID 등 고가치 계정은 문자 인증번호 대신 인증기 앱(Google Authenticator, Microsoft Authenticator)이나 하드웨어 키를 우선하세요.
  \item 신분증 사본에 워터마크: 업무에 필요한 사본에는 "XX 업무 전용"이라고 명시하세요 — 공격자는 유출된 신분증 정보로 당신을 사칭하는 경우가 많습니다.
\end{itemize}

\end{tcbwarn}

\textbf{납치 후 비상 대응 — 속도가 전부입니다}\par

\begin{enumerate}
  \item 즉시 통신사 고객센터에 정지 신고: China Mobile 10086 / China Unicom 10010 / China Telecom 10000. 즉시 정지하고 재발급 업무를 동결해 공격자가 당신의 번호를 계속 쓰지 못하게 하세요.
  \item 다른 기기로 핵심 계정 로그인: PC나 가족 휴대폰으로 은행, Alipay, WeChat, Apple ID의 비밀번호를 즉시 바꾸고 모르는 기기를 로그아웃시키세요.
  \item 결제 계정 동결: Alipay 95188 정지, WeChat 보안 센터 동결, 은행 고객센터 인터넷 뱅킹 동결.
  \item 신분증을 가지고 대리점에 가기: 본인이 신분증을 지참해 직영 대리점에서 새 카드를 재발급받고 번호 사용권을 회복하세요.
  \item 신고: SIM 스와프는 "공민 개인정보 침해죄"에 해당합니다. 증거(정지 시간 기록, 자금 손실, 재발급 기록)를 모두 챙겨 신고하세요.
  \item 전수 점검: 번호를 회복한 뒤 최근 로그인 기록과 자금 흐름을 하나씩 확인해 도용 흔적이 있는지 살펴보세요.
\end{enumerate}

\begin{tcbwarn}{예방이 치료보다 낫다 — 일상 5가지}
\begin{enumerate}
  \item 잠금 화면 비밀번호 + 2단계 인증, 둘 다 켜기
  \item "내 휴대폰 찾기"가 켜져 있는지 확인
  \item SIM 카드 PIN 설정(설정 > 전화 > SIM 카드 PIN). 휴대폰을 잃어버려도 남이 당신의 카드를 쓸 수 없습니다
  \item 출처 불명의 앱을 설치하지 말고, 모르는 링크를 클릭하지 마세요
  \item 중요 데이터 정기 백업(사진, 연락처, 채팅 기록)
\end{enumerate}

\end{tcbwarn}

\begin{tcbpractice}{실습: 나만의 "비상 연락 카드" 만들기}
\begin{enumerate}
  \item 종이 한 장에 다음 번호를 적으세요: 통신사 고객센터(China Mobile 10086 / China Unicom 10010 / China Telecom 10000), 은행 고객센터, 96110 사기 신고, 110 신고, 가족 전화번호.
  \item Apple ID/브랜드 계정의 가입 이메일과 비상 연락처를 적으세요.
  \item 이 종이를 지갑에 넣거나 냉장고에 붙여 두세요 — 휴대폰에 저장하지 마세요. 사고가 났을 때 휴대폰이 손에 없을 수 있기 때문입니다.
  \item 지금 바로 확인: "내 휴대폰 찾기"가 켜져 있는지, SIM 카드 PIN이 설정되어 있는지.
\end{enumerate}

\end{tcbpractice}

XXVII. Diez habilidades de seguridad

La seguridad del teléfono es fundamental. Estos diez consejos te protegen:

\begin{itemize}
  \item \textbf{Activa la autenticación de dos factores (2FA)}: Aunque el estafador tenga tu contraseña, no podrá entrar sin el segundo factor. Actívalo en WeChat, Alipay, banca online, correo, etc.
  \item \textbf{Usa contraseñas diferentes para cuentas diferentes}: Si usas la misma contraseña para todo, una sola filtración compromete todas tus cuentas. Usa un gestor de contraseñas para generar y guardar contraseñas únicas.
\end{itemize}

Activa el pago biométrico

\begin{tcbpractice}{: Activa el pago con Face ID o huella en Alipay/WeChat Pay. Es más seguro que la contraseña y evita que alguien vea tu contraseña.}

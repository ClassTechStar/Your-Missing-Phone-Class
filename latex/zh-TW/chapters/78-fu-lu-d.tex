\bookchapter{附錄D：靠譜資源去哪裡找？}

\booksection{官方支援是首選：}

\begin{itemize}
  \item \textbf{蘋果使用者}：apple.com/cn 和 iCloud.com。
  \item \textbf{安卓使用者}：手機品牌的官網都有"服務與支援"板塊。
  \item \textbf{通用工具}：蘋果用iTunes，華為用華為手機助手，小米用小米換機。
\end{itemize}

\booksection{實用網站與博主：}

\begin{itemize}
  \item \textbf{查技巧}：在B站搜尋"【你的手機型號】技巧"。
  \item \textbf{看測評}：多看幾個不同博主的測評影片。
  \item \textbf{學拍照}：關注手機攝影教程博主。
\end{itemize}

\booksection{安全自查一句話清單：}

\begin{enumerate}
  \item 鎖屏密碼設了嗎？
  \item "查詢我的手機"開了嗎？
  \item 重要賬號的雙重認證開了嗎？
  \item 定期給照片、微信聊天記錄做備份了嗎？
  \item 記住防騙口訣：不輕信、不洩露、不轉賬、不貪心、不急躁。
\end{enumerate}

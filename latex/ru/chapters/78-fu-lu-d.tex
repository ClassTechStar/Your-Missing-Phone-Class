\bookchapter{Приложение D: Ресурсы официальной поддержки}

\booksection{Официальная поддержка — в приоритете:}

\begin{itemize}
  \item \textbf{Пользователи Apple}: apple.com/cn и iCloud.com.
  \item \textbf{Пользователи Android}: на официальных сайтах брендов телефонов есть раздел «Сервис и поддержка».
  \item \textbf{Универсальные инструменты}: для Apple — iTunes, для Huawei — Huawei Phone Assistant, для Xiaomi — Mi Mover.
\end{itemize}

\booksection{Полезные сайты и блогеры:}

\begin{itemize}
  \item \textbf{Поиск советов}: на Bilibili ищите «советы по [модель вашего телефона]».
  \item \textbf{Просмотр обзоров}: смотрите обзоры нескольких разных блогеров.
  \item \textbf{Обучение фотосъёмке}: подписывайтесь на блогеров с уроками по мобильной фотографии.
\end{itemize}

\booksection{Однострочный чек-лист самопроверки безопасности:}

\begin{enumerate}
  \item Установлен ли пароль блокировки экрана?
  \item Включено ли «Найти мой телефон»?
  \item Включена ли двухфакторная аутентификация для важных аккаунтов?
  \item Делаете ли вы регулярные резервные копии фотографий и переписок WeChat?
  \item Запомните правило защиты от мошенников: не доверяйте вслепую, не разглашайте данные, не переводите деньги, не жадничайте, не торопитесь.
\end{enumerate}

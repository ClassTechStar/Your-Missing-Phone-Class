\bookchapter{ภาคผนวก D: หาแหล่งข้อมูลที่น่าเชื่อถือได้ที่ไหน?}

\booksection{การสนับสนุนอย่างเป็นทางการคือทางเลือกแรก:}

\begin{itemize}
  \item \textbf{ผู้ใช้ Apple}: apple.com/cn และ iCloud.com
  \item \textbf{ผู้ใช้ Android}: เว็บไซต์ทางการของแบรนด์มือถือทุกค่ายมีหมวด "บริการและการสนับสนุน"
  \item \textbf{เครื่องมือสากล}: ฝั่ง Apple ใช้ iTunes ฝั่ง Huawei ใช้ Huawei Phone Assistant ฝั่ง Xiaomi ใช้ Mi Mover
\end{itemize}

\booksection{เว็บไซต์และครีเอเตอร์ที่ใช้ได้จริง:}

\begin{itemize}
  \item \textbf{หาเทคนิค}: ค้นหา "[รุ่นมือถือของคุณ] เทคนิค" ใน Bilibili
  \item \textbf{ดูรีวิว}: ดูคลิปรีวิวจากครีเอเตอร์หลายคนมาเทียบกัน
  \item \textbf{เรียนถ่ายรูป}: ติดตามครีเอเตอร์สอนถ่ายภาพด้วยมือถือ
\end{itemize}

\booksection{เช็กลิสต์ความปลอดภัยแบบหนึ่งประโยค:}

\begin{enumerate}
  \item ตั้งรหัสผ่านล็อกหน้าจอหรือยัง?
  \item "ค้นหามือถือของฉัน" เปิดหรือยัง?
  \item การยืนยันสองขั้นของบัญชีสำคัญเปิดหรือยัง?
  \item สำรองรูปภาพและประวัติแชท WeChat เป็นประจำหรือยัง?
  \item จำสูตรกันโจรไว้: ไม่เชื่อง่าย ไม่เปิดเผย ไม่โอนเงิน ไม่โลภ ไม่รีบร้อน
\end{enumerate}

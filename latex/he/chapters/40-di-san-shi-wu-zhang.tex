\bookchapter{פרק 35: ילדים וטלפונים – מדריך חינוכי לעידן הדיגיטלי}

\chapterintro{לא “שטן” ולא “מוקדם = חכם”. לפי גיל.}

\booksection{א', מתי?}

אין תשובה, אך גיל. מוקדם = אלגוריתם; מאוחר = ניתוק.

\begin{itemize}
  \item \textbf{3-6}:לא. אם כן, 15 דק', חינוכי,\textbf{יחד}. ראייה+קשב.
  \item \textbf{7-9}:"שאילה", חוקים, לא פרטי.
  \item \textbf{10-12}:פונקציונלי/שעון, בקרת הורים.
  \item \textbf{13+}:חט"ב, חכם + חוקים.
\end{itemize}

\begin{tcbinfo}{"מספיק"}
לא דגל. 1500-2500. רפורביש.

\end{tcbinfo}

\booksubsection{שעון חכם}

שעון > טלפון. טלפון+מיקום, לא דפדפן/וידאו:

\begin{itemize}
  \item \textbf{Xiaotiantong}:"חברים".
  \item \textbf{Huawei}:מיקום, וידאו.
  \item \textbf{Xiaomi}:זול.
\end{itemize}

קנה:\textbf{4G}, לא 2G/3G.

\booksection{ב', בקרת הורים}

לפני הפעלה, הגדר.

\booksubsection{iOS: Screen Time}

\begin{itemize}
  \item \textbf{App Limits}:הגדרות > Screen Time > Limits.
  \item \textbf{Downtime}:22:00-7:00.
  \item \textbf{Content}:גיל, IAP.
  \item \textbf{Family Sharing}:ניהול מרחוק.
\end{itemize}

\booksubsection{Android: Family Link}

\begin{itemize}
  \item \textbf{Google Family Link}:Google, ניהול מרחוק.
  \item \textbf{Xiaomi Kids}:הגדרות > Kids.
  \item \textbf{Huawei Student}:הגדרות > בריאות > Student.
  \item \textbf{OPPO/vivo Kids}:הגדרות/App.
\end{itemize}

\begin{tcbwarn}{לא "פעם אחת"}
ילדים עוקפים. תקשורת > טכנולוגיה. חודשי.

\end{tcbwarn}

\booksection{ג', Teen Mode}

זוהי פונקציה חובה לפי התקנות, אך\textbf{נדרשת פתיחה יזומה על ידי ההורים וקביעת סיסמה}:

\begin{itemize}
  \item \textbf{Douyin/Kuaishou}:40 דק', 22-6, חינוך.
  \item \textbf{WeChat}:תשלום/תוכן.
  \item \textbf{Gaming}:מדינה, שישי/שבת/חג 20-21, שעה.
\end{itemize}

\textbf{לא “השאל ת”ז“}\par

ילדים משתמשים בת“ז של הורים. שמור.

\booksection{ד', אוריינות}

90\% טכנולוגיה, 10\% שיקול. “איך” > “אל ת”:

\begin{itemize}
  \item \textbf{הגנת פרטיות}:לא פרטים/תמונות/מיקום.
  \item \textbf{Bullying}:קללות/בידוד/תמונות. דווח.
  \item \textbf{ביקורת}:עובדה/דעה, Clickbait.
  \item \textbf{אבטחה}:לא קישורים/QR/App; סיסמה; קוד = רמאי.
\end{itemize}

\begin{tcbpractice}{"הסכם"}
כתוב + חתום:

\begin{itemize}
  \item זמן: 19:30-20:30.
  \item איפה לא: שולחן/מיטה/כיתה.
  \item תוכן: לא App/זרים.
  \item עונש: חצי.
  \item הורים: לא "טלפון".
\end{itemize}

\end{tcbpractice}

\booksection{ה', בריאות}

עיניים/צוואר/שינה:

\begin{itemize}
  \item \textbf{זמן מסך}:3-6: 1h; 6-12: 1h בידור; 12+: 2h.
  \item \textbf{עיניים}:20-20-20, 6 מ'. 1 שעה לפני שינה.
  \item \textbf{תנוחה}:גובה עיניים, 30 דק'.
  \item \textbf{משפחה}:"אזור ללא טלפון".
\end{itemize}

\begin{tcbinfo}{הורים = חומת אש}
הורים ילדים. שנה את עצמך.

\end{tcbinfo}

\booksection{ו', ירושה}

חשבונות/תמונות/משחקים:

\begin{itemize}
  \item \textbf{ירושה}:תעודת פטירה. Legacy Contact.
  \item \textbf{פרטיות}:<14, הסכמה. פרטיות.
  \item \textbf{רישום}:דוא"ל/טלפון של הורה.
\end{itemize}

\begin{tcbwarn}{צד שני}
תינוק נתונים. “שיתוף ילדים” = פרטיות.

\end{tcbwarn}

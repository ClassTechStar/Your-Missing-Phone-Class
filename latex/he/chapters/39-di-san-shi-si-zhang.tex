\bookchapter{פרק 34: מדריך מעמיק לחיבור רכב – מיזוג הטלפון עם המכונית}

\chapterintro{רכב = “גלגלים + סמארטפון”. מכשיר + רכב = חוויה. 3 נתיבים, מערכות, טיפים.}

\booksection{א', 3 נתיבים}

3 גישות:

\begin{itemize}
  \item \textbf{מסך לרכב}:רכב = מסך+רמקול, נתונים מהטלפון. CarPlay, Android Auto, HiCar, CarLife. יתרון: אקוסיסטם; חיסרון: חומרה מבוזבזת.
  \item \textbf{שילוב}:רכב עצמאי + שיתוף. HarmonyOS, DiLink, NIO OS, Li Auto.
  \item \textbf{CarPlay 2.0}:2025, לא רק מסך - דשבורד/AC/מושב. Ferrari, Aston Martin, Porsche.
\end{itemize}

\booksection{ג', HarmonyOS}

CarPlay = “השלך”, HarmonyOS = “משפחה”. הכי גבוה בסין:

\begin{itemize}
  \item \textbf{סופר-דסקטופ}:App מהטלפון. מוזיקה/ניווט, רכבטלפון.
  \item \textbf{המשכיות}:ניווט רכב רגלי.
  \item \textbf{חשבון משותף}:Huawei ID, סנכרון.
\end{itemize}

\booksection{ד', חדשני רכב}

מ“ניווט+מוזיקה” לטרמינל:

\begin{itemize}
  \item \textbf{NIO OS}:NOMI, רב-פקודה. NIO Phone = מפתח+מסך.
  \item \textbf{Li Auto}:מסכים, "משימות".
  \item \textbf{Xiaomi HyperOS}:טלפון+שעון+בית. AC.
  \item \textbf{BYD DiLink}:מסך מסתובב, App Market.
\end{itemize}

\booksection{ה', טלפון כרכב}

אם ישן/גרוע, טלפון? כן, אך תלוי.

\begin{itemize}
  \item \textbf{Ready For / Desktop}:Motorola/Samsung/Huawei, מסך. תאימות משתנה.
  \item \textbf{תושבת vs רכב}:תושבת+ניווט. קטן/חום/סוללה.
  \item \textbf{המלצה}:קצר = תושבת; יומיומי = CarPlay/HiCar.
\end{itemize}

\begin{tcbwarn}{אם הגשת בטעות מידע רגיש, לא מספיק למחוק את הקובץ (הוא עדיין בהיסטוריה), צריך להשתמש ב-}
נהיגה + טלפון = עבירה. תושבת = “ניווט” בלבד. קול/חנה.

\end{tcbwarn}

\booksection{ו', טיפים}

\begin{itemize}
  \item \textbf{CarPlay לא יציב}:Bluetooth חדש; קושחה; כבל.
  \item \textbf{תעבורה}:Hotspot; Wi-Fi; נקה.
  \item \textbf{מצב נהיגה}:iOS Focus; Android Tasker; Huawei.
\end{itemize}

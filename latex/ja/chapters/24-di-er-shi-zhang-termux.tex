\booksubsection{一、Termuxとは}

Termuxの核心的優位性は軽量性と高い拡張性にあり、開発、学習、システム管理など多くのシーンに適しています。標準的なソフトウェアパッケージと精密なターミナルエミュレーションをオープンソースソリューションに統合しています。

\subsubsection*{完全なLinux環境}

Termux\textbf{Bash のみ内蔵}という1種類の Shell のみです。Zsh や fish などの他の Shell を使いたい場合は、パッケージマネージャーで手動インストールが必要です。例：\texttt{pkg install zsh}プロテクトモード\texttt{pkg install fish}。また Termux は Vim、Nano、Emacs などのエディターをサポートし、ネイティブに近いコマンドライン体験を提供します。ユーザーは「pkg install」で2000以上のパッケージをインストールでき、GCC、OpenSSH、SQLMap などの開発·セキュリティツールも含まれます。

\subsubsection*{Linux操作の学習}

リアルな Linux 環境を提供し、コマンドラインやシステム管理の学習に理想的なプラットフォームです。Shell スクリプト作成、Linux ファイル権限管理（例：\texttt{chmod 755}で rwxr-xr-x 権限を設定、\texttt{chown user: group}でファイル所有者を変更、\texttt{ls -\allowbreak l}で owner/group/other の3組9桁の権限を確認）などの基本コマンドを練習できます。これは Unix/Linux の古典的な「3組9桁」権限モデル（owner / group / other × 読み / 書き / 実行）で、Windows NTFS の ACL アクセス制御リストとは完全に異なる体系であることに注意してください。

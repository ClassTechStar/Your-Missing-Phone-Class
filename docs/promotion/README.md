## 核心信息（所有渠道统一口径）

- **一句话**：一门写给所有人的免费手机素养课——84 章，从防诈骗到开发 App。

- **入口**：GitHub 搜「Your-Missing-Phone-Class」；B 站主页 / QQ 群 1074995524
- **三条差异化**（别人没有的）：
  1. 每语言都是完整 84 章翻译（含文言文、阿拉伯语 RTL），不是摘要；

## 发布节奏建议

1. **D0**：Show HN（工作日美东上午）+ 小红书主笔记 + B 站第 1 期；
2. **D1-D2**：评论区互动（HN 答问用 show-hn.md 的预案）；
3. **D3 起**：双日更系列（小红书/B 站同素材分发），每期片尾挂书；
4. **数据回收**：GitHub stars/clone、Release 下载量、QQ 群入群数，决定加更方向。

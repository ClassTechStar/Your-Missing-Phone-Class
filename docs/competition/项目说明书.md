# 项目说明书 ——《你缺失的那门手机课》

> 一句话介绍：一本开源、免费、多语言的手机素养教材——84 章、18.1 万字，从"认识手机硬件"讲到"用 AI 做出自己的第一个 App"，以 19 种语言、四种形态（Web / PWA / APK / PDF）交付，并由自研工具链完成全量自动化质检。

---

## 一、背景与痛点

智能手机已经是水、电、气之外的生活"第四基础设施"，但**没有人教过普通人怎么用**。真实的痛点集中在四类：

1. **基础认知断层**：存储满了不知道删什么、分不清 Wi-Fi 与流量的区别、看不懂处理器与内存参数；
2. **安全问题高发**：针对手机用户的电信诈骗、钓鱼短信、账号盗用逐年上升，长辈是重灾区；
3. **场景无人系统讲解**：手机丢失后的"黄金 30 分钟"、换机迁移、给爸妈配置手机、屏幕时间管理——这些是高频刚需，却散落在碎片化的短视频里；
4. **AI 时代的技能鸿沟**：2025 年起"用 AI 编程"成为新的准入技能，但面向零基础的中文系统教程几乎空白。

市面上的既有方案要么太浅（碎片化短视频），要么太深（维修手册、开发者文档），**把原理讲清楚、覆盖全场景、且能让长辈读懂的书，没有**。本书为此而生。

## 二、目标用户与内容体系

- **普通用户 / 长辈 / 青少年家长**：第 0–36 章，覆盖硬件认知、文件管理、网络、账号安全、防诈骗、支付、摄影、家长管控、数字遗产等全部日常场景；
- **希望进阶的开发者**：第 37–69 章（AI 编程实战篇 33 章）：从向 AI 描述需求、提示词工程，到用 Kotlin / Swift 在安卓与 iOS 上各完成一个真实 App 并上架；
- **每章固定结构**：「本章导览」→ 正文 → 「动手练习」，学得会、练得到。

全书 **11 篇 · 84 个内容区块 · 18.1 万字**（简体中文基准），每章开头有导览、结尾有练习，配「本章小结」与速查表。

## 三、多语言与无障碍：让"所有人"都读得到

- **19 种语言全量翻译**：简体、繁體、粵語、English、한국어、日本語、Русский、Italiano、Português、Español、Français、Deutsch、العربية、עברית、ภาษาไทย、Bahasa Indonesia、Bahasa Melayu、Ελληνικά、文言文——不是机器翻译直出，而是逐节点对齐审计后的成果；
- **RTL 排版**：阿拉伯语与希伯来语做了从右到左的完整排版适配；
- **无障碍设计**：全文 TTS 朗读、无级字号调节、深色模式、PWA 断网可读、第 27 章「父母也能轻松用」长辈适配专题；
- 每种语言都是一个**自足的单文件 HTML**（1–3 MB），双击即可离线打开，不依赖任何服务器。

## 四、技术实现

### 4.1 单一数据源流水线

`manifest/languages.json` 是全项目唯一的元数据真值（语言元数据、检查等级、期望区块数、入口卡片样式、各语言书名）。自研 Python 工具链 **bookkit**（零第三方依赖，标准库实现）驱动全部构建与校验：

```text
Markdown 源稿（source/，逐章）
        │
        ▼  bookkit build
19 种语言单文件 HTML（v1.8/）
        ├──▶ XeLaTeX ──▶ 5 个 Release 共 93 本 PDF
        ├──▶ aapt2 / d8 / apksigner ──▶ 19 个 Android APK
        ├──▶ PWA（sw.js 精准缓存，断网可读）
        ├──▶ 章节自测题库（quiz/，gen_quiz.py 自动生成）
        └──▶ MCP Server（mcp/server.py）
```

### 4.2 质量保障体系（全自动化，当前 0 error / 0 warn）

| 质检门 | 覆盖内容 |
| --- | --- |
| `bookkit lint --all-versions` | 结构、章节锚点、目录、版本串、lang/RTL、NUL 字节、残留字、翻译覆盖率（v1.5–v1.8 + archive 全版本） |
| `bookkit check --claims` | README / index.html 的每一处"宣称数字与链接"与真实内容逐条比对 |
| `bookkit build --verify` | 构建产物与已发布成品逐章比对 |
| `web_smoke.py` | 20 个页面 console 零报错 + 锚点解析 + h3 计数 |
| 逐节点对齐审计 | 译文与 zh-CN 源稿按 DOM 位置 1:1 校验后发布 |

本周期内通过该体系发现并修复的典型问题：th 全文逐词机翻损坏（1,992 处逐节点重写）、en/de/es 共 35 个章节的结构性错位（按 zh-CN 骨架 1:1 重建）、lzh 14 个章节的表格错乱与 NUL 字节、5 种语言 ch3/ch9 的丢段丢句、533 处跨章节注入碎片。

### 4.3 AI 就绪（MCP Server）

`mcp/server.py` 实现标准 MCP（stdio JSON-RPC，零依赖），提供 `list_parts / list_chapters / get_chapter / search / stats` 五个工具——Claude 等 AI 客户端可以**直接查询本书结构、检索全文、读取任意章节**。教科书第一次成为 AI 助手的"可查询数据源"。

## 六、创新点

1. **内容创新**：国内首本把"手机素养 + 反诈 + AI 编程实战"写成一条完整学习路径的开源教材，长辈能读懂、开发者能学完；
2. **工程创新**：自研 bookkit 工具链，把"多语言书籍"变成可构建、可校验、可回归的软件工程产物——宣称值与真实内容逐条比对，杜绝文档漂移；
3. **质量创新**：多语言逐节点 DOM 对齐审计 + 全量自动化质检，19 种语言同一质量水位（0 error / 0 warn）；
4. **AI 创新**：MCP Server 让教材进入 AI 生态，任何 AI 客户端都能把本书当作可查询的知识源；
5. **普惠设计**：单文件离线 HTML + APK + PDF 三线并行，无网环境的用户（正是最需要数字素养的人群）同样读得到。

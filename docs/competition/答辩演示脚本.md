# 答辩演示脚本（5 分钟）

> 目标：让评委在 5 分钟内看懂"这是什么、为什么值一等奖、凭什么可信"。
> 演示前准备：浏览器打开 index.html（本地或 Pages），另开一个标签页停在 v1.8/zh-CN.html 第 0 章；终端准备好 `python -m bookkit lint --all-versions` 与 `python mcp/server.py`。

---

## 0:00–0:40 开场：一句话与一个真实痛点

- 打开 **index.html** 首屏。
- 台词："手机是每个人的第四基础设施，但没有人教过普通人怎么用它。这本书是写给爸妈、写给所有被手机困扰的人的——84 章、18.1 万字、开源免费，已经翻译成 19 种语言。"
- 指出首屏四个数字徽章：84 区块 / v1.8 / 19 语言 / CC BY-NC-SA。

## 0:40–1:40 内容体系：不只是"手机入门"

- 滚动到 **全书目录**：九大部分，从硬件认知 → 安全防诈 → 生活场景 → **AI 编程实战（33 章）**。
- 强调两条独特内容线：① 第 22/32 章的手机丢失黄金 30 分钟与被骗 72 小时急救；② 第 37–69 章用 AI 从零做出并上架 App。
- 点「按需入门」：给爸妈 / 刷机救星 / 急救必备 / 开发者之路——"不必从第一页读到最后一页"。

## 1:40–2:40 阅读器体验：无障碍是设计出来的

- 进入 **v1.8/zh-CN.html**：
  - 调大字号（全文无级缩放）；
  - 切深色模式；
  - 点朗读（TTS 全文读出来）；
  - 刷新页面，展示阅读进度记忆。
- 台词："这些不是附加功能，是给长辈的刚需。第 27 章整章讲怎么给爸妈配手机。"

## 2:40–3:30 多语言与无障碍：19 种语言同一质量

- 回 index.html 滚到 **多语言版本**：19 张语言卡。
- 打开 **ar.html**：整个界面从右到左；再打开 **he.html** 对比。
- 打开 **en.html**："每种语言都是自足的单文件 HTML，双击就能离线看——不需要联网，这正是最需要数字素养的人群所处环境。"

## 3:30–4:20 工程与质量：一等奖的"底气"

- 回 index.html 滚到 **工程实现与质量保障**：讲单一数据源流水线（manifest → bookkit → 19 语言）与四个质量门。
- 切到终端跑 `python -m bookkit lint --all-versions` → **0 error / 0 warn**；`python -m bookkit check --claims` → 宣称值逐条比对通过。
- （加分项）现场用 MCP：`claude mcp add phoneclass -- python mcp/server.py`，然后问 AI "列出全书 11 篇并搜索『黄金 30 分钟』"。
- 台词："这本书不只是写出来的，是用软件工程的方法**构建和校验**出来的——19 种语言同一质量水位，全部自动化，0 错误。"

## 4:20–5:00 多端交付与社会价值收尾

- 滚到 **把书装进口袋**：PDF（5 个 Release 93 本）· APK（19 语言）· 章节自测（218 题）。
- 台词："所有内容 CC BY-NC-SA 开源免费，无广告无追踪。反诈章节可以直接用于社区宣传。我们希望它成为数字素养教育的公共基础设施。"
- 结束页停留在外语卡片与 GitHub 仓库。

## 备答要点（评委常见追问）

| 可能的问题 | 30 秒回答 |
| --- | --- |
| 翻译质量怎么保证？ | 不是机器翻译直出：逐节点 DOM 对齐审计 + bookkit 残留字/覆盖率校验；本周期修复 th 1,992 处、重建 35 个错位章节，全部自动化检出 |
| "0 error" 是什么？ | bookkit 对结构/锚点/目录/版本/lang/RTL/NUL/残留字的全量 lint，以及宣称值与真实内容的逐条比对 |
| 为什么做成单文件 HTML？ | 离线、零依赖、双击可开——目标人群的网络与设备条件恰恰最差；同时仍是 PWA，联网时体验完整 |
| AI 部分会不会过时？ | 第 37–69 章讲的是"怎么向 AI 描述需求"的方法论（提示词工程、验收标准），工具会变，方法不过时；v1.9 已在扩展（81–105 章） |
| 和短视频科普的区别？ | 系统性 + 可校验 + 多端离线 + 多语言；短视频碎片化且无法离线到达无网人群 |
| 如何持续更新？ | Markdown 源稿 → bookkit 一键构建全语言全形态；宣称值校验防止文档与内容脱节 |

## 演示保险

- 若现场无网络：全部演示材料本地可用（HTML/quiz/bookkit 均离线工作，MCP 为本地 stdio 进程）。
- 若 MCP 现场连不上：展示 `python mcp/server.py` 收到 initialize JSON-RPC 的握手输出即可。
- 若时间被压缩到 3 分钟：砍掉 2:40–3:30 的多语言细节，保留 ar.html 一屏带过 + 工程质量门。

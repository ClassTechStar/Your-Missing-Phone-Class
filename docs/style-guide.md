# 风格指南：向《你缺失的那门计算机课》对齐

本项目的 UI 设计与语言表述，以 [《你缺失的那门计算机课》网页版](https://www.criwits.top/missing/)（criwits）为参照。它平易近人、娓娓道来、有分寸的幽默，且没有一丝机器腔。本文记录对齐的要点，供后续写作与改版遵循。

## 一、语言表述

### 1. 标点体例（全项目统一）

- **引号一律用直角引号「」**，嵌套用『』。不用弯引号 "" 与直引号 ""。示例：打开「设置」，点【重命名】。
- **按钮与界面元素用【】**：【此电脑】→【查看】→【文件扩展名】。操作顺序用 → 。
- 专有名词第一次出现时给出学名与俗称的对照：「盘」学名叫做「分区」，顾名思义……
- 代码、命令、文件名保持半角，不套引号。

### 2. 声调

- **第二人称对话感**：多用「你」「我们」。像一位耐心的朋友在讲解，不像教材在宣读。
- **开门见山，问题先行**：章节开头用读者真实会问的问题引入（「C 盘、D 盘都是什么？」「为什么 Word 文档突然打不开了？」），再给答案。避免「随着……的发展」「在本章中我们将」式开场。
- **轻幽默，有分寸**：允许自嘲和戏称（参考 criwits 作者页的「圣马家沟男子职业技术学院」），但不玩梗、不堆表情包。例：「结果就是——满了。」「那可就不好了。」
- **术语先定义再使用**：第一次出现的术语，用一句话说清它是什么、为什么叫这个名字。
- **跨越式引用**：相关内容就地给链接或章名（「如〈认识你的电脑〉一章所言」），不重复展开。
- **禁用的 AI 腔**：「总而言之」「综上所述」「值得一提的是」「不可否认」「随着……的发展」「赋能」「助力」「让我们」；段首排比；空洞的总结句。
- **不确定的数字不编造**：写「大约」「通常」「以官方为准」。

### 3. 结构

- 每章结尾给「练习」或「来动手」，让读者动手而不是只读。
- 附录是查阅入口：按「你现在遇到的事」组织，翻到就能用。
- 修订记录面向读者写，格式参考：`Dark mode: 网页版支持深色模式 (26/6/22)`。

## 二、UI 设计

### 设计 token（对齐 criwits 的纸面风）

| token | 值 | 用途 |
|---|---|---|
| 主色/链接 | `#0074d9`（暗色 `#66b5f2`） | 链接、强调、进度 |
| 访问过的链接 | `#454db6` | 正文链接 |
| 中性灰 | `#f8f9fa / #e9ecef / #dee2e6 / #495057` | 边框、底色、次级文字 |
| 提示盒 | 左缘 0.25rem 粗线 + 浅灰底 `#f1f2f3` | info/tip/quote 类 |
| 警告盒 | 左缘 `#ffc266` + 底 `#fff8ec` | warning |
| 危险盒 | 左缘 `#f44` + 底 `#fdf0ef` | danger |
| 字体 | Inter / Source Han Sans / Noto Sans SC + 系统栈；字距 0.33px | 全站 |
| 标题字重 | 400（层级靠字号与留白，不靠加粗） | h1–h5 |

### 实现位置

- **书页阅读器**：`source/*/template/shell.html` 中的 `<style id="criwits-skin">` 与 `criwits-skin-2` 两段（由 `scripts/inject_criwits_skin.py` 与 `scripts/patch_shell_brand_quotes.py` 注入）。同时定义了此前被引用却未定义的 `--accent-*` 变量。
- **站点门户**：`index.html`（由 `scripts/build_portal.py` 生成目录骨架，`bookkit index` 维护语言卡片与统计数字）。纸面单栏、无渐变英雄区、无徽章墙，改为：目录（锚点直连 v1.9）→ 版本 → 反馈 → 作者 → 修订记录 → 统计 → 许可声明。
- **语言卡片**：`bookkit/index.py` 的 `BLOCK/CARD` 输出朴素的链接列表，不再依赖 Tailwind/Font Awesome。

### 禁止事项

- 不引入新的渐变英雄区、徽章墙、营销横幅。
- 不新增 emoji（书页正文与 UI 一律用文字或 Font Awesome 之外的写法）。
- 不把统计数字加粗到 font-black 之外另起炉灶——门禁（claims）钉住了这些标记。

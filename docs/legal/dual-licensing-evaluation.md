## 一页决策摘要

| 项目 | 结论 |
|------|------|
| **推荐方案** | **方案 C：内容转 CC BY-SA 4.0 + 代码转 Apache-2.0 + 对书名/图标/封面保留商标与形象权利**（即在拟议方案 A 之上补一层名称保护） |
| 核心理由 | ① 去掉 NC 才能真正解决学校/社区/公益机构的合规顾虑，与"写给所有人"的使命一致；② 保留 ShareAlike 防止内容被闭源私有化；③ 代码单独 Apache-2.0 换取专利授权与工具链被机构 IT 部门接纳；④ 商标/名称保护补上"商业搭便车"唯一的实际缺口——BY-SA 允许他人原样卖副本，但不允许冒用官方书名与形象 |

| 不推荐 | 维持 NC + 豁免声明（方案 B）：豁免无法穷举机构场景，模糊性依旧，等于没解决痛点 |
| 执行量级 | 中等：1 个 License 文件拆分为 2 个 + 约 20 处内嵌声明批量更新 + 贡献者同意征集 + 1 张第三方兼容性核对表（见第 4 节清单） |

## 1. 现行许可的运行画像：CC BY-NC-SA 4.0 实际约束了什么

### 1.1 各分发形态下的约束

| 分发形态 | 实际约束（按 CC BY-NC-SA 4.0 条款语义） |
|----------|------------------------------------------|
| 单文件 HTML / PWA | 任何人可复制、修改、再分发，但**修改版必须同许可（ShareAlike）**，且**不得以商业性使用为主要目的**。学校搭内部学习平台一般可主张 NonCommercial，但平台若收学费/广告，边界即模糊 |
| PDF（93 本） | 印刷、复印、分发均受限于 NC。**学校印讲义**是本项目最典型的痛点场景：纯校内教学通常被视为 NC，但收取学费的私立学校/机构是否构成"commercial advantage"无判例定论——这正是机构不敢用的原因 |
| APK | 应用商店免费上架一般不违反 NC；但若商店分成、内嵌广告或预装进收费设备，即进入灰区。被手机厂商预装到售卖机型中大概率违反 NC |
| 翻译（19 种语言） | 翻译属于**改编作品（Adapted Material）**，须以相同许可发布；译者保留署名，原作者须署名。翻译派生物不得转为更开放或更闭源的许可 |
| 教材引用/课程使用 | 教师课堂展示、布置阅读属合理使用或 NC 范围；**培训机构在收费课程中整章引用**（尤其编入讲义）几乎必然落入"商业性使用"，即使引用比例小 |

### 1.2 NC 的模糊地带（真实顾虑清单）

- **学校内部使用算不算商业？** CC 官方 FAQ 认定 NC 看"使用目的"而非"使用者是否营利"，但学校收学费、教材进成本，法务无法给出确定答案。不确定性本身就是采用障碍。
- **培训机构收费课程引用？** 大概率构成商业性使用，机构法务通常直接拒绝。
- **公益组织分发？** 纯公益分发一般合规，但公益组织常有企业赞助、义卖、收费工作坊等混合收入，一混就灰。
- **CC 官方立场**：NC 是"目的导向"的开放性标准，CC 自身不裁决个案；公开判例极少。这意味着**任何"豁免清单"都列举不全**。

结论：NC 对本项目造成的不是"少了一些用户"，而是**目标用户（学校、社区、公益机构）的系统性弃用**——这与"写给所有人"的使命直接矛盾。

## 2. 双许可方案对比评估

| 评估维度 | **A. 全转 CC BY-SA 4.0 + 代码 Apache-2.0**（拟议） | **B. 维持 CC BY-NC-SA 4.0 + 教育/公益豁免声明** | **C. 内容 CC BY-SA + 代码 Apache-2.0 + 商标/名称保护** | **D. 真双许可：NC 公开版 + 付费商业许可**（补充方案） |
|----------|------|------|------|------|
| 机构采用影响 | **高**。学校/机构印讲义、编教材、收费课程引用全部无 NC 障碍 | **低**。豁免需机构自证合规，法务仍会犹豫；且豁免声明的法律效力存疑（需法律顾问确认） | **高**，同 A | **低**。机构用免费版仍背 NC 顾虑；买商业许可反而抬高门槛 |
| 社区贡献影响 | **正面**。贡献者与再创作者明确；与 Wikipedia 等 BY-SA 生态互通 | **中性偏负**。豁免使贡献者面对双重规则，理解成本高 | **同 A**，另需贡献者理解商标政策 | **负面**。社区反感"卖许可"，贡献意愿下降 |
| 防滥用能力（商业搭便车） | **中**。他人可原样售卖副本，但衍生品须同许可开放（SA 阻止闭源私有化） | **强**（NC 挡住商业），但**副作用是同时挡住了目标机构** | **较强**。SA 挡闭源，商标/名称权挡"冒充官方"与品牌蹭用——这是 BY-SA 唯一真实缺口的补丁 | **最强**（NC + 授权双保险），但代价是使命受损 |
| 执行成本 | **中**：License 拆分 + 声明批量更新 + 贡献者同意征集 | **低**：只加一份豁免声明 | **中高**：A 的全部工作 + 商标声明/使用规范（无需注册商标也可依《反不正当竞争法》主张，注册另议） | **高**：需合同模板、收费/维权机制、CLA |
| 与项目使命契合度 | **高** | **中**（表面保留 NC，实际用豁免打补丁，仍是"默认不开放"） | **最高**（开放 + 防冒用官方名义） | **低**（与"全部免费、写给所有人"冲突） |

补充说明：

- **A 与 C 的差异只在商标/名称层**。C 的实现成本中，多出的只是"书名、图标、封面形象保留权利"的一段声明与使用规范，属于低成本高收益。
- **D 虽是字面意义的"双许可"**，但与项目公益定位冲突，仅在"未来必须有收入维持项目"的假设下才值得重估，本期不建议。

## 3. 推荐方案与理由

**明确推荐：方案 C（内容 CC BY-SA 4.0 + 代码 Apache-2.0 + 书名/图标/封面形象保留权利）。**

理由：

1. **痛点只有去 NC 能解**。机构顾虑的本质是 NC 的不确定性，任何豁免都只是把不确定性换算成"逐案自证"，成本仍在机构侧。BY-SA 直接消除该类顾虑。
2. **ShareAlike 是本项目最好的防滥用机制**。教材类内容最怕被闭源私有化后高价售卖改良版；BY-SA 4.0 要求改编（含翻译、摘录改编）以同许可开放，保留了"改进回流公共池"的机制。仅汇编（Collection，如把若干章装进课程包）不触发 ShareAlike，不影响机构按需组课。
3. **代码用 Apache-2.0 而非 MIT**：Apache 的**明示专利授权**与**防御性终止条款**对工具链（bookkit、MCP server）更友好，机构 IT 部门对 Apache-2.0 的合规审查也最熟悉。MIT 可作为备选，但少了专利条款（见第 5 节）。
4. **商标/名称保护补上唯一缺口**：BY-SA 允许他人原样售卖副本（只要署名），这无法也不应阻止；但"用我们的书名和封面冒充官方版"可以通过保留名称与形象权利规制。低成本，且不需要注册商标即可起步（注册与否需法律顾问确认）。
5. **使命一致性**：方案 C 是唯一同时做到"零采用门槛 + 防闭源私有化 + 防冒名"的组合，与"公益定位、写给所有人"完全对齐。

## 5. 风险与回退

1. **不可撤回**：CC 许可一经授予即为永久（被许可人遵守条款的前提下）。relicense 后，任何人都可继续以 CC BY-NC-SA 4.0 使用**旧版本**，你无法收回。回退方案不是"撤销"，而是**新版本停止更新、另起分支**——但旧版授权依旧存续，实际上没有真正回退路径。**这是一次单向门决策，必须在贡献者同意完成后才执行。**
2. **ShareAlike 对教材聚合/翻译的影响**：
   - **翻译**是改编作品，译本必须以 CC BY-SA（或后续版本/兼容许可）发布——这既是义务也是保护（闭源私有翻译不合法）。
   - **摘录改编**（把章节改写成新讲义）触发 ShareAlike，新讲义须同许可开放。
   - **纯汇编不触发**：把原文章节与他人作品装订成课程包（Collection）不要求整个课程包同许可，机构组课自由度不受影响。
   - 与 CC BY-NC 材料混编需谨慎：BY-SA 与 NC 系列兼容性差，改编混编需法律顾问确认。
3. **Apache-2.0 专利条款的意义**：每位代码贡献者**明示授予**其贡献相关的专利使用权；若有人发起专利诉讼，其授权自动终止（防御性终止）。这使 bookkit/MCP server 被企业或机构 IT 采用时无专利后顾之忧——这是 MIT 不具备的。
4. **商标/名称权的局限**：未注册商标主要依《反不正当竞争法》主张"有一定影响的名称"，维权力度弱于注册商标；是否注册、在哪几类注册，需法律顾问确认。
5. **声明与实际不同步的风险**：正文附录（第 115 号附录"开源协议详解"）本身就是教材内容，改许可不改附录会产出"书里教的协议和书用的协议不一致"的硬伤，务必同批次改写。

## 许可条款要点速查

- **CC BY-NC-SA 4.0**：署名 + **非商业性使用** + 相同方式共享。可自由复制、修改、分发，但不得主要出于商业目的使用，改编须以同许可发布；授权永久不可撤回。
- **CC BY-SA 4.0**：署名 + 相同方式共享。去掉了非商业限制：任何人可商用、可印售副本；但改编（含翻译、摘录改写）须以 CC BY-SA 或兼容许可发布；纯汇编不受传染；含数据库特殊权利条款；授权永久不可撤回。
- **Apache-2.0**：宽松许可，可商用、可闭源衍生、可再许可；义务为保留版权与 NOTICE 声明、标注修改；附带**明示专利授权**与**发起专利诉讼即终止**的防御条款；**不授予商标权**。
- **MIT**：极简宽松许可，保留版权声明与许可文本即可任意使用、修改、商用、闭源；无专利条款、无商标条款。
- **SIL OFL 1.1**：字体专用许可。可自由使用、嵌入文档与应用、与任何许可的作品聚合分发；但字体文件本身（及其修改版）再分发须保持 OFL，修改版不得使用保留字体名；**嵌入不要求宿主文档改用 OFL**。

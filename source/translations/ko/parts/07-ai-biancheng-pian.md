## 제7편 〈AI 코딩 실전편〉(37~47장)

{class="chapter-intro mb-4"}
여기까지 읽으셨다면 이제 스마트폰 활용 고수예요. 이번 편에서는 한 걸음 더 나아가 AI가 코드를 짜도록 해 볼 거예요. 2025년 Karpathy가 한마디로 Vibe Coding 운동에 불을 지폈고, 2026년이 된 AI 프로그래밍은 'AI에게 목표 하나만 주면 알아서 계획하고, 일하고, 검증하는' Agentic Engineering으로 진화했어요. 11개 장에 걸쳐 5가지 사고 원칙, 컨텍스트와 요구사항 엔지니어링부터 도구와 모델 선택, 대형 모델 API 실전, 그리고 완성도 높은 3개 프로젝트와 품질 보증 체계까지——'AI를 쓸 줄 아는 사람'에서 'AI 군단을 지휘해 일을 시키는 사람'으로 업그레이드해 드릴게요. 이 말을 기억하세요: 도구는 3개월마다 바뀌지만, 방법론은 3년에 한 번 진화해요. 이 편에서 가르쳐 줄 것은 바로 후자예요.

::: div .info-box .rounded-lg .p-4 .mb-4
{class="font-semibold"}
이번 편 로드맵

{class="mt-1"}
제37~38장 기초 다지기(패러다임 혁명 + 5가지 사고 원칙) → 제39~40장 내공 쌓기(컨텍스트 엔지니어링 + 요구사항 엔지니어링) → 제41~42장 무기 고르기(도구 전체 지도 + 대형 모델 API 실전) → 제43~45장 실전 출전(대화 엔지니어링 + 완성 프로젝트 3개 + 품질 보증) → 제46~47장 한 단계 올라서기(심화 과정 + 빠른 참조 매뉴얼). 기초가 없다면 순서대로 읽기를 권해요. 빨리 만들어 보고 싶다면 바로 제44장으로 넘어가 프로젝트를 따라 해 보세요.
:::

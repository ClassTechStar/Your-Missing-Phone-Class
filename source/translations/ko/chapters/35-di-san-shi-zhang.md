### 제30장: 화면 미러링, 발표 및 차량 연동

{class="chapter-intro mb-4"}
스마트폰 화면이 아무리 커도 7인치이지만, 당신의 TV는 55인치, 프로젝터는 100인치. 스마트폰 화면을 "던져" 큰 화면에 올리면, 경험은 완전히 다른 차원. 이 챕터는 화면 미러링, 발표, 차량 연동이라는 세 가지 고빈도 시나리오를 명확히 설명하여, 스마트폰의 능력을 더 큰 화면으로 확장하도록 돕습니다.

#### 1. 무선 화면 미러링의 세 가지 진영——혼동하지 말 것

##### 각 플랫폼 조작 방법:

- <strong>iPhone</strong>: 제어 센터 > 화면 미러링 > TV/Apple TV 선택. TV가 AirPlay를 지원하지 않으면, Apple TV 박스 또는 AirPlay 지원 TV 스틱 구매.
- <strong>안드로이드</strong>: 알림 바 내리기 > "무선 화면 미러링"/"스마트 화면 미러링"/"다화면 상호작용" 버튼 찾기 > TV 선택. 스마트폰과 TV가 같은 Wi-Fi에 연결되어야 함.
- <strong>만능 방안</strong>: TV가 너무 오래되어 어떤 무선 화면 미러링도 지원하지 않으면, Chromecast 또는 샤오미 박스/화웨이 박스를 구매하여 TV HDMI 포트에 꽂으면, 화면 미러링 수신 가능.

#### 2. 유선 화면 미러링——더 안정적이고, 지연 시간 0

무선 화면 미러링은 편리하지만 지연이 있어, 게임 및 발표 시 경험이 좋지 않음. 유선 화면 미러링은 이 문제를 해결:

- <strong>iPhone</strong>: Lightning/USB-C to HDMI 변환 케이블 1개 필요(약 100-200위안). 꽂으면 스마트폰 화면이 TV/프로젝터 HDMI 포트로 직접 출력.
- <strong>안드로이드</strong>: 일부 스마트폰은 USB-C to HDMI 직접 연결 지원(스마트폰이 DP Alt Mode 지원 필요, 대부분의 플래그십 지원). USB-C to HDMI 케이블 1개 구매.
- <strong>회의실 시나리오</strong>: 자주 스마트폰으로 발표할 필요가 있으면, 가방에 HDMI 변환 케이블을 항상 예비 권장. 회의실 TV/프로젝터에는 거의 모두 HDMI 포트가 있어, 꽂으면 사용 가능, 무선 화면 미러링을 고민하는 것보다 훨씬 신뢰성 있음.

#### 3. 스마트폰이 컴퓨터로——데스크톱 모드

일부 안드로이드 스마트폰은 "데스크톱 모드" 지원——모니터에 연결하면, 스마트폰이 컴퓨터 데스크톱과 유사한 인터페이스를 출력, 마우스 키보드로 조작 가능:

- <strong>Samsung DeX</strong>: 삼성 플래그십의 간판 기능. 모니터에 연결하면 데스크톱 인터페이스 팝업, 다중 창 조작 가능, 경험이 진짜 컴퓨터에 가장 가까움. Bluetooth 키보드 마우스와 함께, 출장 시 노트북 휴대 불필요.
- <strong>화웨이 데스크톱 모드</strong>: 화웨이 Mate 시리즈/Pura 시리즈도 모니터에 연결 후 유사 기능. 다중 창, 파일 관리, 사무 앱 지원.
- <strong>모토로라 Ready For</strong>: Moto 플래그십도 지원, 기능은 DeX와 유사.
- <strong>적용 시나리오</strong>: 경 사무(이메일 답장, 문서 수정), PPT 발표, 대형 화면 영상 시청. 무거운 Excel 조작 또는 전문 디자인에는 부적합.

#### 4. 차량 연동——운전 중 스마트폰 사용의 올바른 방식

운전 중 스마트폰 조작은 위법이지만, 내비게이션, 음악 감상, 전화 받기는 필수. 차량 연동 시스템은 차량 시스템 화면에서 스마트폰의 핵심 기능을 사용할 수 있게 하여, 스마트폰을 한쪽에 두고 만지지 않아도 됨:

- <strong>Apple CarPlay</strong>: iPhone 사용자의 첫 선택. USB 또는 무선으로 차량 시스템에 연결, 차량 시스템 화면에 iPhone의 간소화 인터페이스 표시——내비게이션(가오도/바이두), 음악, 전화, 정보, 팟캐스트. Siri 음성 제어 완전 핸즈프리.
- <strong>Android Auto</strong>: 안드로이드 사용자 대응 방안. 기능은 CarPlay와 유사, Google Maps, Spotify 등 지원. 국내에서 Google 서비스 제한으로 일부 기능 사용 불가.
- <strong>화웨이 HiCar</strong>: 화웨이 자체 개발 방안, 국내 차량 지원률 높음. 내비게이션 음악 외, 화웨이 영상 통화, 주차 영상 융합 등 특징 기능 사용 가능.
- <strong>바이두 CarLife</strong>: 크로스 플랫폼 방안, iOS와 안드로이드 모두 사용 가능. 기능은 적지만 호환성 넓음, 많은 구형 차량은 CarLife만 지원.

#### 5. 회의실 화면 미러링 실전——더 이상 허둥지둥

회의는 화면 미러링의 가장 빈번한 시나리오이며, 가장 문제가 발생하기 쉬운 시나리오. 다음은 실전 경험:

- <strong>사전 도착 테스트</strong>: 회의 시작될 때까지 기다리지 말고 화면 미러링 연결 금지. 10분 일찍 도착, 연결 방식 테스트. Wi-Fi 화면 미러링 실패 확률은 생각보다 훨씬 높음.
- <strong>유선 방안 Plan B 준비</strong>: 가방에 HDMI 변환 케이블 예비. 무선 화면 미러링 연결 안 될 때, 유선은 구원 밧줄.
- <strong>알림 미리보기 끄기</strong>: 화면 미러링 시 위챗 메시지가 회의실 대형 화면에 표시. 화면 미러링 전에 설정에서 "잠금 화면 알림 내용 미리보기" 끄기, 또는 "발표 모드" 켜기(일부 스마트폰 지원, 화면 미러링 시 자동으로 알림 숨김).
- <strong>"발표 문서" 사용, "스마트폰 조작"이 아님</strong>: PPT를 발표해야 하면, PPT를 스마트폰에 저장하여 WPS로 열어 전체 화면 재생, 스마트폰 데스크톱 전체 화면 미러링이 아님. 이렇게 더 전문적이고 매끄러움.

::: div .practice-box .rounded-lg .p-4 .mt-4
{class="font-semibold"}
<i class="fas fa-hands mr-2"></i>실습: 스마트폰에서 TV로 화면 미러링 한 번 완료

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 스마트폰과 TV가 같은 Wi-Fi에 연결되어 있는지 확인.
2. 스마트폰으로 사진이나 영상을 하나 열어 봅니다.
3. 무선 화면 미러링을 시도해 봅니다 (iPhone은 화면 미러링, Android는 무선 화면 미러링 버튼 사용).
4. 실패할 경우 TV가 해당 프로토콜을 지원하는지 확인하거나, DLNA 푸시를 시도해 봅니다 (사진/영상 앱에서 "화면 미러링" 버튼 클릭).
5. 화면 미러링이 성공하면, 스마트폰에서 다른 작업을 해 보면서 큰 화면에 동기 표시되는지 확인합니다.
:::

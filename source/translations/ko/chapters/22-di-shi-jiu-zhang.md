### 제19장: 고장 진단과 자가 구조

{class="chapter-intro mb-4"}
스마트폰도 사람과 같아서, 가끔 "병"에 걸립니다. 버벅거림, 강제 종료, 검은 화면, 충전 불량...대부분의 문제는 사실 그렇게 무섭지 않습니다, 수리센터에 보내기 전에 스스로 먼저 시도해 볼 수 있습니다. 이 장은 당신의 "스마트폰 응급 매뉴얼"입니다——저비용 방법부터 먼저 시도, 안 되면 전문 의사를 찾으세요.

#### 하나, 스마트폰이 버벅거리고 발열——가장 자주 묻는 질문

솔직히, 스마트폰을 1년쯤 쓰면 버벅거리기 시작하는 건 너무 정상입니다. 원인이 스마트폰이 고장 난 것이 아닐 수도, 더 많은 경우 "먼지 쌓임"——쓰레기 파일, 백그라운드 프로세스, 저장 공간이 서서히 채워지는 것.

##### 먼저 진단, 서둘러 수리하지 마세요:

1. <strong>저장 공간 확인</strong>: 설정 → 저장 공간에서 잔여 공간 확인. 10% 미만이면 시스템이 매우 버벅거림, 공간 확보하려고 애쓰고 있기 때문. 제 경험: 최소 15%-20% 잔여 공간 유지해야 스마트폰이 비교적 원활.
2. <strong>전력 소모 순위 확인</strong>: 배터리 설정에서 지난 24시간 전력 소모 순위 확인. 특정 앱이 대부분 차지하지만 거의 안 썼다면, 백그라운드에서 도는 것. 바로 제거 또는 백그라운드 제한.
3. <strong>최근 무엇을 했는지 연상</strong>: 시스템 업그레이드 후 버벅거린 건가?(대형 버전 업데이트 후 며칠간 버벅거림은 정상, 시스템이 백그라운드에서 인덱스 재구축). 특정 새 앱 설치 후 버벅거린 건가?(제거해 보기).
4. <strong>사용 환경 보기</strong>: 스마트폰이 태양 아래 폭로, 두꺼운 케이스에 충전하면서 게임, 발열은 필연적. 고온은 CPU 자동 주파수 낮춤 유발, 스마트폰이 갑자기 버벅거리는 느낌. 식힌 후 재시도.

<strong>치료 방법(간단에서 복잡으로)</strong>: 스마트폰 재부팅(60% 문제 해결) → 저장 공간 정리(불필요한 앱과 비디오 삭제) → 특정 앱이 문제면 캐시 삭제 또는 제거 후 재설치 → 마지막 수단: 데이터 백업 후 공장 초기화.

#### 둘, 앱 강제 종료, 응답 없음——앱이 말을 안 들어요

특정 앱이 열자마자 강제 종료, 또는 쓰다가 갑자기 멈춤. 처리 흐름은 의사 문진처럼, 한 단계씩:

1. <strong>먼저 닫았다 다시 열기</strong>: 백그라운드에서 앱을 스와이프하여 닫고, 다시 열기. 대부분의 일시적 버그는 이것으로 해결.
2. <strong>앱 업데이트</strong>: 앱 스토어에서 업데이트 있는지 확인. 때로는 앱 버전이 너무 오래되어 시스템과 호환 안 됨.
3. <strong>권한 확인</strong>: 일부 앱은 특정 권한이 있어야 정상 작동, 하지만 안 줌. 예: 카메라 앱에 카메라 권한 안 주면 열자마자 강제 종료. 설정에서 해당 앱 찾기, 필요한 권한 모두 부여.
4. <strong>캐시 삭제</strong>: 설정 → 앱 관리 → 해당 앱 찾기 → 저장 공간 → 캐시 삭제. 주의: "캐시 삭제"지 "데이터 삭제"가 아님! 데이터 삭제는 앱 내 로그인 상태와 설정을 전부 삭제, 앱 공장 초기화와 같음.
5. <strong>제거 후 재설치</strong>: 마지막 수단. 제거 전 이 앱의 데이터가 손실되는지 먼저 확인——위챗은 먼저 채팅 기록 백업, 게임은 먼저 계정이 휴대폰 번호 바인딩되었는지 확인.

#### 셋, 충전 불량 또는 충전 느림——배터리 탓이 아닐 수도

충전 불량은 특히 불안을 유발하는 문제, 하지만 많은 경우 원인은 액세서리에, 스마트폰 고장이 아닙니다.

- <strong>먼저 충전 포트 점검</strong>: 이쑤시개 또는 비전도성 작은 도구로, 충전 포트 안의 먼지와 보풀을 가볍게 제거. 제가 직접 겪은 일——주머니에서 실 한 오라기가 떨어져 충전 포트를 막고, 꽂으면 접촉 불량인 줄 알았는데, 꺼내니 해결.
- <strong>케이블과 충전 헤드 교체 시도</strong>: 케이블 손상률이 충전 헤드보다 훨씬 높음, 특히 자주 감아서 쓰는 케이블. 확실히 문제 없는 케이블과 충전 헤드로 교차 테스트, 어떤 액세서리가 고장인지 빠르게 확인.
- <strong>무선 충전 문제</strong>: 무선 충전 사용 시, 스마트폰 케이스가 너무 두꺼운지, 케이스 뒤에 금속 조각(자석 거치대 등)이 있는지 확인. 그리고 스마트폰을 충전 판 정중앙에 정확히 놓기——비뚤어지면 충전 안 될 수 있음.
- <strong>충전 느림</strong>: 충전 헤드 출력이 충분한지 확인(iPhone 고속 충전은 최소 20W PD 충전 헤드 필요), 케이블이 고속 충전 지원하는지(모든 케이블이 3A 이상 전류 통과 가능한 건 아님), 스마트폰이 너무 뜨거운지(너무 뜨거우면 자동으로 출력 낮춰 배터리 보호).

#### 넷, 네트워크 연결 불량, Wi-Fi 자주 끊김

외부에서 모바일 데이터 잘 쓰다가, 집에 와서 Wi-Fi 연결 안 됨; 또는 Wi-Fi 연결되어 있는데 인터넷 안 됨. 이 순서대로 점검:

1. <strong>비행기 모드 on/off</strong>: 제어 센터에서 비행기 모드 켜고 5초 후 끄기. 스마트폰이 다시 네트워크 검색하게 함, 매우 효과적.
2. <strong>Wi-Fi "잊기" 후 재연결</strong>: Wi-Fi 설정에서, 네트워크 이름 옆 느낌표(Android는 톱니바퀴) 클릭, "이 네트워크 무시" 또는 "잊기" 선택, 그리고 다시 비밀번호 입력해 연결.
3. <strong>라우터 재부팅</strong>: 많은 가정의 라우터가 몇 달 안 꺼졌을 것, 오래 쓰면 불안정해짐. 전원 뽑고 30초 후 다시 꽂기, 대부분의 Wi-Fi 문제 해결.
4. <strong>스마트폰 문제인지 확인</strong>: 다른 기기가 같은 Wi-Fi에 정상 연결되나? 모두 정상인데 당신 스마트폰만 안 되면, 스마트폰을 재부팅하거나 네트워크 설정 초기화 필요(설정 → 일반 → 전송 또는 초기화 → 네트워크 설정 초기화, 데이터 삭제 안 함, 하지만 모든 Wi-Fi 비밀번호 삭제).

#### 다섯, 화면 문제: 터치 불량, 깜빡임, 잔상

- <strong>터치 불민감</strong>: 먼저 강화 유리 필름 떼고 필름 탓인지 확인——싼 강화 필름은 오래 쓰면 터치에 영향. 화면에 물이 있거나 손에 기름 있어도 터치 드리프트. 둘 다 아니면, 재부팅 후 재시도.
- <strong>화면에 잔상/잔영(번인)</strong>: 오랫동안 같은 화면 표시(예: 항상 화면 켜두고 Douyin 시청), OLED 화면에 "잔영" 남음. 화면 고장 아님, 일시적. 화면 끄고 30분 휴식하면 보통 회복.
- <strong>화면 깜빡임</strong>: 저밝기에서 깜빡임이라면, PWM 디더링 문제일 수 있음, OLED 화면에 흔함. 설정에서 "DC 디더링" 또는 "플리커 방지" 옵션 찾기, 켜면 크게 개선. 모든 스마트폰에 이 기능 있는 건 아님.
- <strong>화면의 한 영역이 완전히 검게/밝게</strong>: 이건 비교적 심각, 대부분 화면 물리적 손상, 화면 교체 필요. 비공식 수리로 교체한 화면은 색상과 밝기가 보통 순정만 못, 방수에도 영향.

#### 여섯, 부팅 불가, Logo 화면에서 멈춤——먼저 진정

이런 상황은 가장 심장이 뛰게 하지만, 진정하고, 먼저 이것들을 시도:

- <strong>30분 충전 후 말하기</strong>: 많은 경우 그냥 전력이 완전히 소진된 것. 순정 충전기 꽂고, 최소 30분 대기, 부팅 재시도. 일부 스마트폰은 전력 소진 후 일정 충전량 되어야 반응.
- <strong>강제 재부팅</strong>: iPhone 풀스크린 모델은 볼륨 업 한 번, 볼륨 다운 한 번, 측면 전원 버튼 길게 누름, 화면에 Apple Logo 나올 때까지(10-15초 누름 필요할 수도). Android 공통 방법: 전원 버튼 10초 이상 길게 누름, 진동 또는 화면 점등까지.
- <strong>부팅 화면에서 반복 재부팅</strong>: 이 상황을 "화이트 Apple"(iPhone) 또는 "Logo 카드"(Android)라 함. 강제 재부팅 안 되면, 복구 모드 진입해 컴퓨터로 복구 필요할 수도. iPhone은 컴퓨터 연결 후 iTunes/Finder 열고, 복구 모드 진입 후 "업데이트" 선택("복원" 아님), 시스템 재설치하지만 데이터 보존. Android는 Fastboot 또는 Recovery 모드 진입, 각 브랜드 조합 키 다름, 스마트폰 모델+"복구 모드 진입" 검색 권장.
- <strong>위 방법 모두 안 됨</strong>: 전문 수리에 도움 요청. 데이터가 백업되어 있다면 너무 걱정 안 해도 됨.

#### 일곱, 소리 문제: 스피커 안 울림, 통화 소리 작음

- <strong>스피커 소리 없음</strong>: 먼저 무음 모드 아닌지 확인(iPhone 측면 무음 스위치), 방해 금지 모드, 또는 볼륨이 최저로 눌려 있지 않은지. 바보 같아 들리지만, 이런 경우가 40%. 그리고 Bluetooth가 어떤 이어폰이나 스피커에 연결되어 있지 않은지 확인.
- <strong>통화 중 상대방이 당신 말을 못 들음</strong>: 마이크 구멍이 막히지 않았는지 확인——스마트폰 하단의 작은 구멍은 먼지에 막히기 쉬움. 부드러운 브러시로 가볍게 청소. 바늘이나 이쑤시개로 세게 찌르지 마세요, 방진망 손상.
- <strong>소리 거칠음/소리 찢어짐</strong>: 스피커 물 침수로 인한 것이라면——드라이어 열풍으로 부풀지 마세요! 키친타올로 표면 수분 흡수, 그리고 자연 건조. 인터넷에서 음파 배수 앱이 어느 정도 효과 있다고 함(저주파 소리 재생으로 물 진동 배출), 시도해 볼 만함.

#### 여덟, 공식 수리 찾기, 함정 피하기

위 방법 모두 시도해도 안 되면, 전문 수리를 찾아야 합니다. 하지만 수리 시장은 깊어서, 제가 직접 겪은 함정과 경험을 이야기하겠습니다:

- <strong>진짜 공식 찾기, "공식처럼 보이는" 곳 말고</strong>: 브랜드 공식 홈페이지(Apple.com.cn, Huawei.com.cn 등)에서 "공인 서비스 제공자" 리스트 찾기. 길거리 사과 로고 건 비공인점은 순정 액세서리가 아닐 수 있고, 수리 후 방수 사라짐.
- <strong>수리 전 필수 작업</strong>: 모든 데이터 백업(수리 중 데이터 손실 안 된다고 기대하지 마세요), 모든 중요 계정 로그아웃(Apple ID, 위챗, Alipay), "내 스마트폰 찾기" 끄기. 일부 수리점은 잠금 화면 비밀번호 제공 요구, 프라이버시 위험 있음——먼저 직접 계정 로그아웃 후 수리 맡기는 게 좋음.
- <strong>화면 교체 함정</strong>: 비공식 화면은 "원압 화면"(순정 유리 교체), "후압 화면"(비순정 유리), "조립 화면"(전부 비순정)으로 나뉨. 가격 차이 몇 배, 하지만 표시 효과와 내구성도 큰 차이. 스마트폰이 아직 보증 기간 내라면, 성실하게 공식 경유.
- <strong>배터리 교체 함정</strong>: 비순정 배터리는 용량 허위 표기 가능, 그리고 반년 쓰면 순정 배터리 2년 손실보다 더 큰 손실. Apple 배터리 교체 공식 가격은 비공식보다 많이 비싸지 않음, 공식 경유 권장.
- <strong>데이터 복구 함정</strong>: 스마트폰 침수/낙하 후, 수리 시 "데이터 복구 추가 요금"이라면 주의——일부 불량 업체는 고장 정도를 과장해 더 청구. 정상적인 데이터 복구는 먼저 견적 후 조작, 그리고 복구 실패 시 무료.

<i class="fas fa-exclamation-triangle mr-2"></i>만능 첫 수: 스마트폰 재부팅

어떤 문제를 겪든——버벅거림, 강제 종료, 네트워크 연결 불량, 소리 이상——먼저 스마트폰 재부팅. 이 말은 건성으로 들리지만, 제 경험상, 최소한 60%의 작은 문제는 재부팅 후 해결. 스마트폰은 컴퓨터와 같아서, 오래 쓰면 메모리에 온갖 잡동사니 쌓이고, 재부팅은 비우고 다시 시작. 그러니 다음번 스마트폰 문제 시, 서둘러 "어떡하지" 검색하지 말고, 재부팅부터 하고 보세요.

<i class="fas fa-hands mr-2"></i>지금 바로 외우기: 이 구명 조작은 완벽히 숙지

{class="list-decimal pl-6 mt-1 space-y-1"}
1. <strong>강제 재부팅</strong>: 풀스크린 iPhone은 볼륨 업 → 볼륨 다운 → 전원 버튼 길게 눌러 Logo 나올 때까지. Android는 전원 버튼 10-15초 길게 눌러 진동까지.
2. <strong>충전 포트 청소</strong>: 작은 도구(이쑤시개 또는 SIM 꺼내는 핀)로 충전 포트의 먼지 가볍게 청소.
3. <strong>Wi-Fi 재연결</strong>: Wi-Fi 설정에서 현재 Wi-Fi "잊기", 비밀번호 다시 입력해 연결.
4. <strong>비행기 모드 on/off</strong>: 제어 센터에서 비행기 모드 켜기, 마음속으로 5초 세기, 끄기, 네트워크 복구되는지 보기.
5. 이 조작들의 단계를 스크린샷으로 저장, 또는 메모에 적어두기. 문제 발생 시 허둥지둥 검색하지 말고, 메모를 바로 펼치면 됨.

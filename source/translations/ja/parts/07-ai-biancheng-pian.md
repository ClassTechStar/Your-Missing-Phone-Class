## 七、AIプログラミング実践編（第37-47章）

{class="chapter-intro mb-4"}
ここまで読み終えたあなたは、もうスマホ使いの達人です。このパートでは、さらにもう一大歩を踏み出します：AI にコードを書いてもらうのです。2025年、Karpathy のひと言が Vibe Coding のムーブメントに火をつけ、2026年には AI プログラミングは「AI に目標を与えれば、自分で計画し、作業し、検収する」Agentic Engineering へと進化しました。全11章にわたる内容——5大思考原則、コンテキストと要件のエンジニアリングから、ツールとモデルの選定、大規模モデル API の実践、さらに3つの完全プロジェクトと1そろいの品質保証体制まで——「AI を使える」から「AI の軍団を指揮して働かせる」レベルへあなたを引き上げます。あの言葉を忘れないでください：ツールは3か月ごとに改訂され、方法論は3年かけてようやく進化する。このパートで教えるのは、後者のほうです。

::: div .info-box .rounded-lg .p-4 .mb-4
{class="font-semibold"}
このパートの道しるべ

{class="mt-1"}
第37〜38章で基礎固め（パラダイム革命＋5大思考原則） → 第39〜40章で内功を鍛える（コンテキストエンジニアリング＋要件エンジニアリング） → 第41〜42章で武器を選ぶ（ツールの全景＋大規模モデル API 実践） → 第43〜45章で実戦へ（対話エンジニアリング＋3つの完全プロジェクト＋品質保証） → 第46〜47章で階段を上る（上級への道＋クイックリファレンス）。ゼロからの初心者は順番に読むのがおすすめ。早く何かをつくりたい人は、第四十四章へ飛んで、そのままプロジェクトをやってみましょう。

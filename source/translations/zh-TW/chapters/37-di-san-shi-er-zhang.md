### 第三十二章：手機安全急救手冊

{class="chapter-intro mb-4"}
這一章是一份"應急預案"。希望你永遠用不上，但如果真的遇到手機丟失、被盜、被詐騙的情況，這份手冊能幫你把損失降到最低；地震、暴雨等災害來臨時，手機同樣是接收預警、定位求救、保持聯絡的工具。建議你現在就通讀一遍，然後把關鍵步驟截圖儲存，或者列印出來放在家裡——因為出事的時候你的手機可能已經不在手上了，災害時則可能沒電或沒訊號。

#### 場景零：地震 / 極端天氣——手機怎麼幫你保命

防的是人身安全，不是帳號資金。預警設定詳見 第十三章「天氣預警、自然災害預警與地震預警」；這裡只講警報響起之後該怎麼做。

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
地震警報響了：先躲後撤，別只顧著拍影片

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 就近避險：趴下、掩護、抓牢（桌下、承重牆角、堅固傢俱旁），護住頭頸；遠離玻璃、外牆、吊燈。
2. 不要盲目衝樓：主震往往只有十幾秒到幾十秒，樓梯間可能更危險；電梯絕對不能用。
3. 震停後再有序撤離：走樓梯、注意餘震與掉落物；到開闊地，遠離電線杆、廣告牌、危房。
4. 手機用在刀刃上：給緊急聯絡人發簡短訊息（「我在XX，安全/受傷，需要幫助」）比打長電話更省電；能發簡訊/微信時優先文字。
5. 沒訊號時：見 第七章 衛星 SOS / 衛星訊息（機型支援時）；或到高處、開闊地再試；部分場景下無網藍芽對講亦有幫助。
6. 關閉非必要功能：應急時開飛航模式再定時開、關藍芽掃描、降亮度，能多撐幾小時；把最後一格電留給報平安與救援資訊。
:::

::: div .warning-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
暴雨 / 颱風 / 山洪：預警階段就要行動

{class="list-disc pl-6 mt-1 space-y-1 text-sm"}
- 看到紅色預警：儘量減少外出，遠離地下空間、下穿橋、河道、陡坡。
- 在戶外被困：往堅固建築物高處走，勿強行涉水（積水可能有井蓋缺失與漏電）；打 119/110 時說清地標與水位。
- 出行前：用天氣 App 與當地預警公眾號確認風險；長途自駕避開山區臨水臨崖路段。
- 家人互報：約定「若失聯，以最後微信/簡訊定位為準」，避免各自瘋狂撥號耗光電量。
:::

::: div .practice-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
平時就做好的 4 件事

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 開啟系統地震預警 / 正規預警 App，並允許其突破靜音。
2. 在通訊錄置頂 2-3 位「緊急聯絡人」，鎖定畫面介面可顯示（iOS/安卓醫療急救卡或鎖定畫面資訊）。
3. 家裡和包裡備行動電源；長途出行前充滿電並帶線。
4. 記住至少一個「不用通訊錄也能打」的號碼（家人手機號），寫在紙上放錢包。
:::

#### 場景一：手機丟了/被偷了——黃金30分鐘

手機丟失後的前30分鐘是"黃金時間"，處理得當可以保住你的錢財和隱私。按以下順序操作，一步都不要跳：

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
丟失後30分鐘標準操作流程

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 借別人手機撥打自己號碼（第1分鐘）：可能只是掉在附近，好心人接了就能拿回來。
2. 遠端鎖定手機（第2-5分鐘）：用別人的手機或電腦登入查詢服務： iPhone：iCloud.com > 查詢 > 選你的裝置 > 標記為丟失
3. 安卓各品牌：華為cloud.huawei.com / 小米i.mi.com / OPPO cloud.oppo.com 等
4. 掛失SIM卡（第5-10分鐘）：打電信業者客服電話（移動10086/聯通10010/電信10000），報手機丟失要求暫停SIM卡服務。這一步最關鍵——騙子拿到你的SIM卡就能接收驗證碼，重置你所有密碼。
5. 凍結支付帳戶（第10-20分鐘）： 支付寶：95188 掛失，或在別人手機上登入支付寶 > 我的 > 設定 > 安全中心 > 緊急凍結
6. 微信：110 報警後聯絡微信客服，或在微信安全中心 > 凍結帳號
7. 銀行App：撥打銀行卡背面的客服電話，要求凍結網銀
8. 通知親友（第20-25分鐘）：在朋友圈或讓家人幫忙發訊息，通知親友手機丟失，防止騙子用你的身份騙別人。
9. 報警（第25-30分鐘）：撥打110或去最近的派出所報案，拿到報案回執。後續保險理賠、銀行糾紛都需要這個回執。
:::

#### 場景二：被騙了——72小時黃金處理期

發現自己被騙後，最關鍵是冷靜。慌亂中做錯誤決定會導致二次損失。按以下步驟操作：

1. 立即停止一切轉帳操作：不管騙子說什麼，不要再轉一分錢。"再轉一筆保證金就能退回之前的錢"是經典二次詐騙話術。
2. 保留所有證據：不要刪聊天紀錄！不要刪通話紀錄！截圖儲存聊天紀錄、轉帳紀錄、對方帳號資訊。這些都是報案和追回資金的關鍵證據。
3. 立即撥打96110：這是全國反詐專線。接線員會指導你做緊急止付——如果轉帳時間不長（通常24小時內），銀行有可能凍結對方帳戶攔截資金。
4. 撥打110報警：帶上手機、身份證、轉帳憑證去最近的派出所做筆錄。
5. 聯絡銀行/支付平臺：告知被騙情況，要求凍結涉案帳戶。如果是信用卡被盜刷，要求銀行啟動拒付流程。
6. 修改所有密碼：在另一臺安全裝置上修改你的Apple ID/品牌帳號、微信、支付寶、銀行App的密碼，開啟雙重認證。

#### 場景三：手機中了病毒/木馬——怎麼辦？

如果你發現手機出現以下症狀——莫名其妙跳出廣告、自動安裝奇怪App、通電話費暴增、用量異常消耗——很可能是中了惡意軟體：

- 第一步：進入安全模式——安卓手機長按電源鍵關機，再長按電源鍵開機，開機震動後長按音量減鍵不放，直到進入安全模式（左下角會顯示"安全模式"字樣）。安全模式下所有第三方App被停用，方便排查。
- 第二步：解除安裝可疑App——在安全模式下進入設定 > 應用管理，按時間排序，找到最近安裝的不認識的App解除安裝掉。
- 第三步：安裝安全App掃描——下載"騰訊手機管家"或"360手機衛士"做一次全盤掃描。
- 第四步：恢復原廠設定（終極方案）——如果以上方法無效，備份重要資料後恢復原廠設定。注意：恢復原廠設定會刪除所有資料，一定要先備份照片、通訊錄等重要檔案。
- iPhone基本不會中毒——iOS的沙盒機制讓惡意軟體很難存活。如果你的iPhone出現異常，大機率是某個App的bug或設定問題，不是病毒。恢復原廠設定能解決99%的問題。

#### 場景四：帳號被盜——快速奪回控制權

1. 立即修改密碼：如果你還能登入帳號，第一時間改密碼。新密碼要和舊密碼完全不同。
2. 踢掉其他裝置：在帳號安全設定裡找到"登入裝置管理"，把不認識的裝置全部踢下線。
3. 檢查登入記錄：檢視最近7天的登入記錄，如果有異地登入，說明帳號確實被盜了。
4. 開啟雙重認證：如果你還沒開雙重認證，現在立刻開。這是防止帳號再次被盜最有效的方法。
5. 檢查繫結資訊：檢查帳號繫結的手機號、信箱有沒有被改。如果被改了，用帳號申訴功能找回。
6. 檢查支付設定：如果被盜的是微信/支付寶，檢查免密支付、自動扣款有沒有被篡改，銀行卡有沒有被新增到陌生帳戶。

#### 場景五：收到勒索資訊——不要怕，不要付

常見的勒索套路有兩種：①"我有你的不雅影片/照片，不給錢就發給你通訊錄裡所有人"；②"你的手機被駭客控制了，不給錢就鎖死"。遇到這種情況：

- 99.9%是詐騙：他們手裡根本沒有你的任何隱私資料。群發同樣的勒索資訊給幾萬人，總有人害怕付錢。
- 不要回復，不要付錢：回覆了等於告訴對方"這個號碼有人用"，你會被標記為"可勒索目標"，後續騷擾更多。
- 截圖儲存證據：然後拉黑對方。
- 修改密碼：如果擔心，修改一下你主要帳號的密碼，圖個安心。
- 如果真的有隱私洩露風險：報警。警方有處理這類案件的經驗。

#### 場景六：AI換臉/AI擬聲詐騙——眼見不再為實

2024年起，AI換臉和AI擬聲技術已經能讓騙子在視訊通話裡"變成"你的家人、領導、朋友的臉和聲音。"媽，我出事了，快轉錢過來"——影片裡的人長得、聽起來都跟你兒子一模一樣，但其實是假的。這是當前最難防、也最危險的詐騙手法之一。

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
第一步：識別破綻——AI偽造的四個常見漏洞

{class="list-disc pl-6 mt-1 space-y-1"}
- 眨眼頻率異常：真人每分鐘眨眼15-20次，AI換臉往往眨眼過少或節奏僵硬。
- 嘴型與音訊不同步：仔細看口型和聽到的聲音之間，會有零點幾秒的錯位。
- 面部邊緣模糊：臉的輪廓、耳朵附近、頭髮邊緣容易出現"毛邊"或閃爍。
- 光影方向不一致：臉上的高光、陰影和背景的光照方向對不上，或者側臉時五官"跟著轉"得不對。
:::

::: div .info-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
第二步：三招驗證對方真假

{class="list-disc pl-6 mt-1 space-y-1"}
- 要求做特定動作：讓對方轉頭、捂臉、用手擋住嘴巴再做開合動作。AI換臉在遮擋和大角度轉頭時最容易"露餡"——臉會變形或跟不上動作。
- 問只有對方知道的問題：編一個假問題，比如"上次咱家狗送去哪家醫院看的？"——如果是騙子，他答不上來或者支支吾吾。
- 回撥已知號碼：結束通話影片，用你通訊錄裡存的號碼直接回撥過去。騙子控制不了真實的手機號，一撥就露餡。
:::

::: div .warning-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
第三步：確認被騙後的報警流程

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 立即停止轉帳：再"急"也先停一下，凡是催你"快轉帳、別掛電話"的，幾乎都是騙子。
2. 保留全部證據：錄屏、截圖儲存視訊通話畫面、聊天紀錄、對方帳號、轉帳憑證——這些是技術鑑定的關鍵材料。
3. 撥打96110反詐專線：告知是"AI換臉/擬聲"類詐騙，接線員會啟動緊急止付。
4. 撥打110報警：帶齊證據去派出所做筆錄，特別說明使用了AI偽造技術，便於警方立案定性。
5. 通知親友：騙子可能用你的偽造影片去騙別人，提前在朋友圈或家庭群裡發個提醒。
:::

#### 場景七：SIM swap攻擊（SIM劫持）——你的號碼被"偷"走了

這是一種很多人沒聽過、但危害極大的攻擊。SIM swap（SIM卡劫持）指的是攻擊者透過偽造你的身份資訊，冒充你到營業廳補辦一張新的SIM卡。一旦補辦成功，你手機的訊號會突然消失，而攻擊者的手機插著那張新卡，能收到你所有的簡訊驗證碼——支付寶、銀行、微信，全部門戶大開。

::: div .info-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
怎麼發現？SIM swap的三個預警訊號

{class="list-disc pl-6 mt-1 space-y-1"}
- 手機突然顯示"無服務"/"無SIM卡"，但你明明沒動過卡，重啟也沒用——這往往是被劫持的瞬間。
- 收到電信業者發來的"補卡成功"或"業務辦理成功"簡訊——但你本人沒辦過。
- 突然收不到驗證碼，但其他簡訊也收不到——因為簡訊被劫持到了攻擊者的卡上。
:::

::: div .warning-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
防護措施——把SIM卡也"上鎖"

{class="list-disc pl-6 mt-1 space-y-1"}
- 設定SIM卡PIN碼：路徑 設定 &gt; 電話 &gt; SIM卡PIN碼。開啟後，每次手機重啟或換卡，都要輸PIN才能用這張卡。攻擊者就算拿到卡也用不了。
- 開啟電信業者二次驗證：登入中國移動/聯通/電信App，找到"安全中心"或"業務辦理驗證"，開啟非本人補卡簡訊提醒和業務辦理二次密碼驗證。這樣別人去補你的卡時，營業員會要求額外的身份核驗。
- 重要帳號別隻用簡訊驗證：銀行、Apple ID等高價值帳號，優先用認證器App（Google Authenticator、微軟Authenticator）或硬體金鑰，而不是簡訊驗證碼。
- 身份證影印件加水印：辦理業務需要的影印件寫明"僅供XX業務使用"——攻擊者往往靠洩露的身份證資訊冒充你。
:::

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
被劫持後的應急處理——速度就是一切

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 立即撥打電信業者客服掛失：移動10086 / 聯通10010 / 電信10000，要求立即停機並凍結補卡業務，阻止攻擊者繼續使用你的號碼。
2. 用其他裝置登入關鍵帳號：用電腦或家人手機，立即修改銀行、支付寶、微信、Apple ID的密碼，並踢掉陌生裝置。
3. 凍結支付帳戶：支付寶95188掛失，微信安全中心凍結，銀行客服凍結網銀。
4. 帶身份證去營業廳：本人持身份證到自營廳補辦新卡，還原號碼使用權。
5. 報警：SIM swap已構成"侵犯公民個人資料罪"，帶齊證據（停機時間記錄、資金損失、補卡記錄）報案。
6. 全面排查：還原號碼後，逐一檢查近期登入記錄和資金流水，確認有沒有被冒用過的痕跡。
:::

::: div .warning-box .rounded-lg .p-4 .mt-4
{class="font-semibold"}
預防勝於治療——日常5件事

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 鎖定畫面密碼 + 雙重認證，兩個都開
2. "查詢我的手機"確認開啟
3. SIM卡設定PIN碼（設定 > 電話 > SIM卡PIN碼），丟了手機別人不能用你的卡
4. 不安裝來歷不明的App，不點陌生連結
5. 定期備份重要資料（照片、通訊錄、聊天紀錄）
:::

::: div .practice-box .rounded-lg .p-4 .mt-4
{class="font-semibold"}
動手：做一份屬於你的"應急聯絡卡"

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 找一張紙，寫下以下號碼：電信業者客服（移動10086/聯通10010/電信10000）、銀行客服、96110反詐專線、110報警電話、家人電話。
2. 寫下你的Apple ID/品牌帳號的註冊信箱和備用聯絡方式。
3. 把這張紙放在錢包裡或貼在冰箱上——不要存在手機裡，因為出事時手機可能不在身邊。
4. 現在就檢查："查詢我的手機"是否已開啟，SIM卡PIN碼是否已設定。
:::

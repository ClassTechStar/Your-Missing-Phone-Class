### Bab 4: Memasang dan Mengelola Aplikasi — "Paket Keterampilan" Ponsel

{class="chapter-intro mb-4"}
Aplikasi membuat ponsel bisa melakukan apa saja, tetapi juga perlu dikelola dengan baik. Sama seperti Anda memberikan meja kerja dan mengalokasikan izin kepada karyawan baru, memasang aplikasi juga memerlukan proses standar.

#### 1. Toko Resmi: "Supermarket Aplikasi" Paling Aman

- <strong>Android</strong>: Google Play (luar negeri) atau toko bawaan masing-masing merek (seperti Huawei AppGallery, Mi Store).
- <strong>: Pengguna biasa tidak dapat mengaktifkan mode pengembang lengkap, membutuhkan akun Apple Developer berbayar.</strong>: Hanya App Store.
- <strong>HarmonyOS</strong>: Huawei AppGallery.

Arti penting keamanan inti: telah melalui peninjauan, pembaruan terjamin, pembayaran aman. Panduan tindakan:<strong>prioritaskan hanya mengunduh dari toko resmi!</strong>

#### 2. Mode Murni/Proteksi: Aktifkan "Tembok Anti-Virus" Ponsel

Merek domestik mainstream (Huawei, Xiaomi, OPPO, vivo, Honor) semua memiliki <strong>Mode Murni</strong> atau <strong>Mode Proteksi</strong> bawaan, ini adalah sakelar keamanan tingkat sistem.<strong>Sangat disarankan agar semua pengguna mengaktifkannya</strong>.

##### 1. Apa sebenarnya itu?

Fungsi inti Mode Murni (juga disebut "Mode Proteksi") adalah memblokir pemasangan aplikasi pihak ketiga <strong>: saat aktif, sistem akan</strong> hanya mengizinkan pemasangan aplikasi dari toko aplikasi resmi <strong>, paket instalasi yang diunduh dari browser, QR code, perangkat lunak chat, dan saluran lain akan langsung diblokir, mencegah perangkat lunak berbahaya dari sumbernya.</strong>2. Pengguna yang Sesuai

##### Pengguna lanjut usia

- <strong>: Tidak bisa membedakan iklan "resmi" dan "palsu", Mode Murni adalah jimat paling aman.</strong> Pengguna yang tidak sensitif terhadap izin aplikasi
- <strong>: Tidak perlu memasang aplikasi niche, beta, game server luar negeri.</strong> Semua pengguna yang ingin meningkatkan keamanan perangkat
- <strong>: Bahkan penggemar, lebih baik aktif daripada tidak — jika benar-benar butuh sementara, matikan sebentar saja.</strong>3. Jalur Aktivasi (contoh Huawei/Xiaomi)

##### Huawei/HarmonyOS

- <strong>: [Pengaturan] &gt; [Sistem &amp; Pembaruan] &gt;</strong>[Mode Murni] <strong>, pilih "Aktifkan".</strong> Xiaomi
- <strong>Xiaomi</strong>[Lindungi Privasi] <strong>atau [Pengaturan] &gt; [Pengaturan Aplikasi] &gt; [Pemasangan Aplikasi], matikan "Pasang aplikasi tidak dikenal".</strong> OPPO/vivo
- <strong>: Sebagian model dapat di-unlock, perlu pengajuan.</strong>[Pasang Aplikasi Sumber Eksternal] <strong>, matikan otorisasi satu per satu.</strong>4. Mekanisme Inspeksi Keamanan Toko Aplikasi

##### Toko aplikasi bukan "pajangan", di belakangnya ada jalur produksi keamanan lengkap:

Pemindaian virus

- <strong>: Setiap aplikasi sebelum dipublikasikan akan dipindai bersama oleh beberapa mesin antivirus, mengidentifikasi karakteristik trojan dan virus yang diketahui.</strong> Audit izin
- <strong>: Toko akan meninjau apakah izin yang diminta aplikasi "masuk akal" — aplikasi senter meminta izin kontak? Langsung ditolak atau ditarik.</strong> Sertifikasi pengembang
- <strong>: Publikasi memerlukan kualifikasi perusahaan, KTP pribadi atau kartu kredit. Jika ada masalah bisa ditemukan orangnya, bukan "aplikasi hitam".</strong> Pemantauan berkelanjutan

##### Pemindaian virus penuh berkala

- <strong>: Gunakan pusat keamanan bawaan ponsel (seperti Huawei Phone Manager, Mi Security Center) memindai sekali sebulan.</strong> Berhati-hati memberikan izin sensitif
- <strong>: Kontak, SMS, lokasi, kamera, mikrofon — kelima "izin berisiko tinggi" ini harus diaudit ketat.</strong> Perhatikan anomali konsumsi daya dan kuota
- <strong>: Ponsel tiba-tiba panas, baterai cepat berkurang, kuota berjalan tengah malam — kemungkinan besar ada "parasit" tersembunyi di latar belakang.</strong> Jika terpaksa harus memasang aplikasi pihak ketiga:

Pastikan sumber benar-benar tepercaya.

1. Periksa persyaratan izin dengan teliti sebelum memasang.
2. Pindai dengan aplikasi keamanan setelahnya.
3. Saran terakhir: Di pengaturan sistem, matikan izin "Pasang aplikasi tidak dikenal".

#### Pernahkah Anda bertanya-tanya, paket instalasi yang diunduh dari toko aplikasi, apa sebenarnya isinya? Memahami komposisi paket instalasi dapat membantu Anda lebih memahami cara kerja aplikasi, juga dapat membantu saat mengalami masalah mengetahui dari mana harus memeriksa.

1\. Struktur File APK Android

##### APK (Android Package Kit) pada dasarnya adalah arsip ZIP, setelah diekstrak dapat dilihat direktori dan file inti berikut:

AndroidManifest.xml

- <strong>: "KTP" dan "buku petunjuk" aplikasi. Mencatat nama paket aplikasi, nomor versi, izin yang diperlukan, versi sistem yang didukung, Activity masuk, dan informasi inti lainnya. Sistem membaca file ini pertama kali saat memasang aplikasi.</strong> classes.dex
- <strong>: Kode inti aplikasi. Kode sumber Java/Kotlin setelah dikompilasi menjadi bytecode Dalvik, disimpan dalam file ini. Satu aplikasi mungkin memiliki beberapa file dex (seperti classes2.dex, classes3.dex).</strong> resources.arsc
- <strong>: Tabel indeks sumber daya yang dikompilasi. Mencatat ID semua sumber daya dan korespondensinya.</strong> Direktori res/
- <strong>: Folder sumber daya. Berisi gambar, file layout, string, definisi warna, dll. Gambar dengan resolusi berbeda ditempatkan di folder drawable berbeda (seperti drawable-hdpi, drawable-xhdpi).</strong> Direktori assets/
- <strong>: Folder sumber daya asli. Menyimpan sumber daya yang tidak dikompilasi, seperti file halaman web, font, audio, dll. Saat aplikasi berjalan dapat dibaca melalui AssetManager.</strong> Direktori lib/
- <strong>: Folder pustaka native. Menyimpan file .so yang telah dikompilasi (hasil kompilasi kode C/C++), diklasifikasikan berdasarkan arsitektur CPU (seperti arm64-v8a, armeabi-v7a). Game dan aplikasi yang membutuhkan komputasi performa tinggi biasanya memiliki direktori ini.</strong> Direktori META-INF/
- <strong>: Folder informasi tanda tangan. Berisi tiga file MANIFEST.MF, CERT.SF, CERT.RSA, digunakan untuk memverifikasi integritas dan tanda tangan APK.</strong>2. Struktur File IPA iOS

##### IPA (iOS App Store Package) juga arsip terkompresi, strukturnya sedikit berbeda:

Direktori Payload/

- <strong>: Lokasi konten inti. Di dalamnya ada folder .app, berisi semua konten aplikasi.</strong> Info.plist
- <strong>: File konfigurasi aplikasi, mirip dengan AndroidManifest.xml Android. Mencatat ID aplikasi, versi, persyaratan izin, perangkat yang didukung, dll.</strong> File yang dapat dieksekusi
- <strong>: Program utama dengan nama yang sama dengan folder .app, adalah file biner format Mach-O yang dikompilasi.</strong> Direktori Frameworks/
- <strong>: Pustaka dinamis dan kerangka kerja yang menjadi dependensi aplikasi.</strong> File sumber daya
- <strong>: Gambar, audio, video, dan sumber daya lainnya, biasanya disimpan di dalam folder .app.</strong> Direktori _CodeSignature/
- <strong>: Informasi tanda tangan kode, digunakan untuk memverifikasi integritas dan asal aplikasi.</strong>3. Mekanisme Verifikasi Tanda Tangan

##### Anda mungkin menemukan, ukuran aplikasi yang ditampilkan di toko aplikasi berbeda dengan ruang yang digunakan setelah dipasang. Ini karena:

Ukuran unduhan

- <strong>: Ukuran APK/IPA setelah dikompres.</strong> Ukuran pemasangan
- <strong>: Ukuran setelah diekstrak, biasanya jauh lebih besar dari ukuran unduhan.</strong> Penggunaan runtime
- <strong>: Saat aplikasi berjalan juga akan menghasilkan cache, file data, menempati lebih banyak ruang.</strong> Sarana optimasi aplikasi modern:

App Bundle (Android)

- <strong>: Teknologi distribusi dinamis Google Play. Saat mengunduh, pengguna hanya mendapatkan sumber daya yang sesuai dengan perangkatnya (seperti hanya mengunduh gambar resolusi layar yang sesuai), sangat mengurangi ukuran unduhan.</strong> App Thinning (iOS)
- <strong>: Teknologi serupa, Apple akan otomatis memotong sumber daya yang tidak diperlukan sesuai perangkat.</strong> Unduhan sesuai permintaan
- <strong>: Aplikasi besar seperti game dapat mengunduh paket inti terlebih dahulu, kemudian mengunduh paket sumber daya.</strong> Tahukah Anda: Mengapa ada paket instalasi aplikasi yang sangat besar?

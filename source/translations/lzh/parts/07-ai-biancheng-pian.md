## 七、AI編程實戰篇（第37-47章）

{class="chapter-intro mb-4"}
讀至於此，爾已為玩機之高手矣。此一篇，請再邁一大步：使 AI 為爾作碼。2025 年 Karpathy 一言而燃 Vibe Coding 之運；至 2026 年，AI 編程已進為 Agentic Engineering——予 AI 一之，彼自規劃、自用力、自驗收。凡十一章：自五大思維之則、上下文與需求之工，至工具與模型之選、大模型 API 之實戰，終以三完整之項目與一套質量保障之制——引爾自「會用 AI」進乎「指 AI 之軍以任事」。謹識斯言：工具每三月一迭代，方法每三年一進化。此篇所授，後者也。

::: div .info-box .rounded-lg .p-4 .mb-4
{class="font-semibold"}
本篇之途

{class="mt-1"}
第三十七、三十八章奠其基（範式之革+五大思維之則）→ 第三十九、四十章練內功（上下文之工+需求之工）→ 第四十一、四十二章擇其器（工具全景+大模型 API 實戰）→ 第四十三至四十五章赴戰陣（對話之工+三完整之項目+質量保障）→ 第四十六、四十七章登其階（進階之途+速查之冊）。零基者宜順序而讀；欲速成其物者，徑躍第四十四章，從而作項目。
:::

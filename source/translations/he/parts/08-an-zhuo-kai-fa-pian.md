## ח. פיתוח אנדרואיד בפועל (פרקים 48-58)

{class="chapter-intro mb-4"}
החלק השביעי לימד אתכם לפקד על AI שכותב קוד; בחלק הזה נוריד את הידע לקרקע האנדרואיד: מהיכרות עם אנדרואיד והתקנת Android Studio, דרך Kotlin ו-Jetpack Compose, ועד שני פרויקטים שלמים ועלייה ל-Google Play. לאורך כל הדרך אין צורך ב-Mac — Windows מספיק. אחרי 11 פרקים תוכלו לבנות אפליקציה אמיתית שתותקן בטלפונים של 300 מיליון אנשים.

::: div .info-box .rounded-lg .p-4 .mb-4
{class="font-semibold"}
המסלול של החלק

{class="mt-1"}
פרקים 48-49 מניחים את היסודות (היכרות עם אנדרואיד + הקמת הסביבה) → פרקים 50-51 מחזקים את השליטה הפנימית (Kotlin + Jetpack Compose) → פרקים 52-53 בוחרים נשק (ארבעת הרכיבים העיקריים + נתונים ורשת) → פרקים 54-56 יוצאים לקרב (שני פרויקטים שלמים + עלייה ל-Google Play) → פרקים 57-58 עולים במדרגות (דרך ההתקדמות + מדריך עיון מהיר). למי שמתחיל מאפס מומלץ לקרוא ברצף; מי שרוצה להגיע לתוצאה מהר — יכול לדלג ישר לפרק 54 ולעבוד על הפרויקט.
:::

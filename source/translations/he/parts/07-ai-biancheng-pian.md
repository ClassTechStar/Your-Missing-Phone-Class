## ז. תכנות עם AI בפועל (פרקים 37-47)

{class="chapter-intro mb-4"}
אם הגעתם עד כאן, אתם כבר מומחי סמארטפון לכל דבר. בחלק זה נעשה עוד צעד ענק קדימה: לתת ל-AI לכתוב קוד בשבילכם. ב-2025 משפט אחד של Karpathy הצית את תנועת ה-Vibe Coding, ונכון ל-2026 התכנות בעזרת AI כבר התפתח ל-"Agentic Engineering" — "נותנים ל-AI מטרה, והוא מתכנן, עובד ומאמת את התוצאות בעצמו". 11 פרקים — החל מחמשת עקרונות החשיבה, הנדסת ההקשר והנדסת הדרישות, דרך בחירת כלים ומודלים ועבודה מעשית עם API של מודלים גדולים, ועד שלושה פרויקטים שלמים ומערכת שלמה להבטחת איכות — יקפיצו אתכם מ"יודעים להשתמש ב-AI" ל"מפקדים על צבא שלם של AI". זכרו את המשפט: הכלים מתחדשים כל שלושה חודשים, והמתודולוגיה מתפתחת רק כל שלוש שנים. החלק הזה מלמד אתכם את השנייה.

::: div .info-box .rounded-lg .p-4 .mb-4
{class="font-semibold"}
מסלול הדרך בחלק זה

{class="mt-1"}
פרקים 37–38 מניחים את היסודות (מהפכת הפרדיגמה + חמשת עקרונות החשיבה) → פרקים 39–40 מחזקים את הבסיס הפנימי (הנדסת ההקשר + הנדסת דרישות) → פרקים 41–42 בוחרים כלי עבודה (מפת הכלים + עבודה מעשית עם API של מודלים גדולים) → פרקים 43–45 יוצאים לשדה הקרב (הנדסת דיאלוג + שלושה פרויקטים שלמים + הבטחת איכות) → פרקים 46–47 מטפסים מדרגה (הדרך להתקדמות + מדריך לעיון מהיר). למי שמתחיל מאפס מומלץ לקרוא לפי הסדר; מי שרוצה להגיע לתוצאה מהר יכול לדלג ישר לפרק 44 וללוות את הפרויקט צעד-צעד.
:::

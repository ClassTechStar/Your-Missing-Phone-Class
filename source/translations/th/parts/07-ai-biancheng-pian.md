## 7. ภาคลงมือทำเขียนโค้ดด้วย AI (บทที่ 37-47)

{class="chapter-intro mb-4"}
อ่านมาถึงจุดนี้ คุณก็เป็นเซียนมือถือคนหนึ่งแล้ว ในภาคนี้ เราจะก้าวไปอีกก้าวใหญ่: ให้ AI ช่วยเขียนโค้ด ปี 2025 Karpathy พูดประโยคเดียวจุดประกายขบวนการ Vibe Coding และมาถึงปี 2026 การเขียนโปรแกรมด้วย AI ได้วิวัฒน์เป็น Agentic Engineering ที่ "ให้เป้าหมายแก่ AI แล้วมันวางแผน ลงมือ และตรวจรับเอง" อีก 11 บท ตั้งแต่หลักคิดทั้งห้า การจัดการบริบทและความต้องการ ไปจนถึงการเลือกเครื่องมือกับโมเดล การใช้งาน API ของโมเดลใหญ่จริง ๆ และสามโปรเจกต์ครบวงจรพร้อมระบบการันตีคุณภาพ พาคุณจาก "ใช้ AI เป็น" ไต่ขึ้นไปถึง "คุมกองทัพ AI ให้ทำงาน" จำประโยคนี้ไว้: เครื่องมือหมุนเวอร์ชันทุกสามเดือน แต่วิธีคิดพัฒนาขึ้นรอบสามปีเท่านั้น สิ่งที่ภาคนี้จะสอนคุณคืออย่างหลัง

เส้นทางของภาคนี้

{class="mt-1"}
บทที่ 37-38 รากฐาน (ปฏิวัติกระบวนทัศน์ + หลักคิดทั้งห้า) → บทที่ 39-40 ฝึกพลังภายใน (Context Engineering + Requirements Engineering) → บทที่ 41-42 เลือกอาวุธ (ภาพรวมเครื่องมือ + ลงมือใช้ API โมเดลใหญ่) → บทที่ 43-45 ลงสนามจริง (การทำงานกับแชท + สามโปรเจกต์ครบวงจร + การการันตีคุณภาพ) → บทที่ 46-47 ไต่บันได (เส้นทางสู่ขั้นสูง + คู่มือฉับไว) ถ้าเป็นมือใหม่เกลือ 0 แนะนำให้อ่านเรียงลำดับ ถ้าอยากได้ของเร็ว ข้ามไปบทที่ 44 แล้วตามทำโปรเจกต์ได้เลย
:::

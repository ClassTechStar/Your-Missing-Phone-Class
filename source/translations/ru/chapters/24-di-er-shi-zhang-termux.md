### Приложение к главе 20: Termux — портативная среда Linux-терминала на устройстве Android

{class="chapter-intro mb-4"}
Если вам кажется, что режим разработчика недостаточно «хардкорен» и вы хотите опробовать полноценную командную строку Linux на телефоне, то Termux — именно то, что нужно. Без прав root он превращает обычный Android-телефон в портативную Linux-рабочую станцию — мощный инструмент для продвинутых пользователей, исследующих мобильную разработку и администрирование.

#### I. Что такое Termux

Termux — это приложение с открытым исходным кодом, эмулятор терминала и среда Linux, специально разработанное для устройств Android. Оно предоставляет полноценный опыт Linux shell на телефоне без прав root. Как лёгкое приложение (установочный пакет около 30 МБ), Termux поддерживает богатую экосистему программ через систему управления пакетами APT, позволяя пользователям запускать на мобильном устройстве Python, Node.js, Git, SSH и другие инструменты, и даже развёртывать серверы или проводить тесты на проникновение.

Ключевые преимущества Termux — лёгкость и высокая расширяемость, подходящие для множества сценариев: разработки, обучения и системного администрирования. Он объединяет стандартные пакеты с точной терминальной эмуляцией в одном решении с открытым исходным кодом.

#### II. Основные функции и характеристики

##### 🖥️ Полноценная среда Linux

Termux <strong>встроенно включает только Bash</strong> в качестве оболочки. Если вы хотите использовать другие оболочки, такие как Zsh или fish, их нужно установить вручную через менеджер пакетов, например: <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">pkg install zsh</code> или <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">pkg install fish</code>. Termux также поддерживает редакторы Vim, Nano, Emacs, предоставляя почти нативный опыт командной строки. Пользователи могут установить 2000+ пакетов через «pkg install», включая GCC, OpenSSH, SQLMap и другие инструменты разработки и безопасности.

##### 📦 Мощное управление пакетами

Использует менеджер пакетов APT (аналог Debian и Ubuntu), позволяющий установить тысячи Linux-пакетов, включая инструменты разработки, сетевые утилиты и др. Поддерживает среды нескольких языков программирования: Python, Ruby, Node.js, Go, Rust, Swift и другие.

##### 🔒 Безопасность и сетевые функции

- <strong>Удалённое SSH-соединение</strong>: поддерживает функции SSH-клиента и сервера, позволяет удалённо подключаться к другим устройствам или превратить телефон в SSH-хост.
- <strong>Инструменты шифрования</strong>: предоставляет OpenSSL и другие инструменты шифрования, поддерживает шифрование данных и безопасную связь.
- <strong>Развёртывание сервера</strong>: можно настроить Nginx или Apache для развёртывания статического веб-сервера.

##### 🔧 Системная интеграция и расширения

- Доступ к разрешениям хранилища телефона для локального управления файлами.
- Вызов датчиков, камеры и других аппаратных функций Android через плагин Termux:API.
- Поддержка Bluetooth-клавиатур и внешних дисплеев, полноценная поддержка мыши.

#### IV. Руководство по установке и настройке

##### 📥 Шаги установки

1. <strong>Скачайте приложение</strong>: скачайте и установите Termux из официальных источников (F-Droid или GitHub), права root не требуются.
2. <strong>Инициализация системы</strong>: после первого запуска дождитесь завершения «Installing bootstrap packages».
3. <strong>Получите разрешения хранилища</strong>: выполните <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">termux-setup-storage</code> для получения доступа к файловой системе телефона.
4. <strong>Обновите источники ПО</strong>: выполните <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">pkg update &amp;&amp; pkg upgrade</code> для обновления списка пакетов.

##### ⚙️ Базовая оптимизация

- <strong>Смена зеркала</strong>: используйте команду <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">termux-change-repo</code> для смены зеркала через графический интерфейс (рекомендуется зеркало университета Цинхуа).
- <strong>Настройка горячих клавиш</strong>: клавиша уменьшения громкости эмулирует Ctrl, клавиша увеличения громкости — Esc, повышая эффективность ввода.
- <strong>Оформление интерфейса</strong>: установите Zsh + Oh My Zsh, настройте тему и плагины.

#### V. Типичные сценарии применения

##### 💻 Мобильная разработка и тестирование

Развёртывание полной среды разработки на телефоне, написание и выполнение скриптов Python, компиляция программ на C с помощью GCC, управление репозиториями кода через Git, синхронизация с удалёнными серверами через SSH.

##### 🖥️ Администрирование серверов

Удалённое управление серверами через SSH, выполнение системного обслуживания, анализа логов и других задач — решение проблем сервера в любое время и в любом месте.

##### 📚 Изучение работы с Linux

Предоставляет реальную среду Linux — идеальную платформу для изучения командной строки и системного администрирования. Можно практиковать написание Shell-скриптов, управление правами доступа к файлам Linux (например, <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">chmod 755</code> устанавливает биты прав rwxr-xr-x, <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">chown user:group</code> изменяет владельца файла, <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">ls -l</code> показывает три группы по девять битов прав: owner/group/other) и другие базовые команды. Обратите внимание: это классическая Unix/Linux модель прав «три группы по девять битов» (owner / group / other × чтение / запись / выполнение), которая принципиально отличается от списков управления доступом (ACL) Windows NTFS — это две совершенно разные системы.

##### 🔐 Тестирование сетевой безопасности

Установка инструментов безопасности Nmap, SQLMap, Hydra, Metasploit для сетевого сканирования и тестирования на проникновение.

#### VI. Версия и совместимость

Последняя стабильная версия Termux — v0.118.2, подходит для устройств с Android ≥ 7. Обратите внимание, что Termux может быть нестабилен на Android 12 и выше; рекомендуется следить за официальным журналом обновлений для получения актуальной информации о совместимости.

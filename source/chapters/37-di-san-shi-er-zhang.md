### 第三十二章：手机安全急救手册

{class="chapter-intro mb-4"}
这一章是一份"应急预案"。希望你永远用不上，但如果真的遇到手机丢失、被盗、被诈骗的情况，这份手册能帮你把损失降到最低；地震、暴雨等灾害来临时，手机同样是接收预警、定位求救、保持联络的工具。建议你现在就通读一遍，然后把关键步骤截图保存，或者打印出来放在家里——因为出事的时候你的手机可能已经不在手上了，灾害时则可能没电或没信号。

#### 场景零：地震 / 极端天气——手机怎么帮你保命

防的是人身安全，不是账号资金。预警设置详见 <a href="#di-shi-san-zhang" class="text-primary hover:underline">第十三章</a>「天气预警、自然灾害预警与地震预警」；这里只讲<strong>警报响起之后</strong>该怎么做。

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-house-crack mr-2"></i>地震警报响了：先躲后撤，别只顾着拍视频

{class="list-decimal pl-6 mt-1 space-y-1"}
1. <strong>就近避险</strong>：趴下、掩护、抓牢（桌下、承重墙角、坚固家具旁），护住头颈；远离玻璃、外墙、吊灯。
2. <strong>不要盲目冲楼</strong>：主震往往只有十几秒到几十秒，楼梯间可能更危险；电梯绝对不能用。
3. <strong>震停后再有序撤离</strong>：走楼梯、注意余震与掉落物；到开阔地，远离电线杆、广告牌、危房。
4. <strong>手机用在刀刃上</strong>：给紧急联系人发简短消息（「我在XX，安全/受伤，需要帮助」）比打长电话更省电；能发短信/微信时优先文字。
5. <strong>没信号时</strong>：见 <a href="#di-qi-zhang-jichu" class="text-primary hover:underline">第七章</a> 卫星 SOS / 卫星消息（机型支持时）；或到高处、开阔地再试；部分场景下无网蓝牙对讲亦有帮助。
6. <strong>关闭非必要功能</strong>：应急时开飞行模式再定时开、关蓝牙扫描、降亮度，能多撑几小时；把最后一格电留给报平安与救援信息。
:::

::: div .warning-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-cloud-showers-heavy mr-2"></i>暴雨 / 台风 / 山洪：预警阶段就要行动

{class="list-disc pl-6 mt-1 space-y-1 text-sm"}
- 看到<strong>红色预警</strong>：尽量减少外出，远离地下空间、下穿桥、河道、陡坡。
- 在户外被困：往坚固建筑物高处走，勿强行涉水（积水可能有井盖缺失与漏电）；打 119/110 时说清地标与水位。
- 出行前：用天气 App 与当地预警公众号确认风险；长途自驾避开山区临水临崖路段。
- 家人互报：约定「若失联，以最后微信/短信定位为准」，避免各自疯狂拨号耗光电量。
:::

::: div .practice-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-hands mr-2"></i>平时就做好的 4 件事

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 开启系统地震预警 / 正规预警 App，并允许其突破静音。
2. 在通讯录置顶 2-3 位「紧急联系人」，锁屏界面可显示（iOS/安卓医疗急救卡或锁屏信息）。
3. 家里和包里备充电宝；长途出行前充满电并带线。
4. 记住至少一个「不用通讯录也能打」的号码（家人手机号），写在纸上放钱包。
:::

#### 场景一：手机丢了/被偷了——黄金30分钟

手机丢失后的前30分钟是"黄金时间"，处理得当可以保住你的钱财和隐私。按以下顺序操作，一步都不要跳：

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-exclamation-circle mr-2"></i>丢失后30分钟标准操作流程

```html
<ol class="list-decimal pl-6 mt-1 space-y-1">
                            <li><strong>借别人手机拨打自己号码</strong>（第1分钟）：可能只是掉在附近，好心人接了就能拿回来。</li>
                            <li><strong>远程锁定手机</strong>（第2-5分钟）：用别人的手机或电脑登录查找服务：
                                <ul class="list-disc pl-6 mt-1">
                                    <li>iPhone：iCloud.com > 查找 > 选你的设备 > 标记为丢失</li>
                                    <li>安卓各品牌：华为cloud.huawei.com / 小米i.mi.com / OPPO cloud.oppo.com 等</li>
                                </ul>
                            </li>
                            <li><strong>挂失SIM卡</strong>（第5-10分钟）：打运营商客服电话（移动10086/联通10010/电信10000），报手机丢失要求暂停SIM卡服务。这一步最关键——骗子拿到你的SIM卡就能接收验证码，重置你所有密码。</li>
                            <li><strong>冻结支付账户</strong>（第10-20分钟）：
                                <ul class="list-disc pl-6 mt-1">
                                    <li>支付宝：95188 挂失，或在别人手机上登录支付宝 > 我的 > 设置 > 安全中心 > 紧急冻结</li>
                                    <li>微信：110 报警后联系微信客服，或在微信安全中心 > 冻结账号</li>
                                    <li>银行App：拨打银行卡背面的客服电话，要求冻结网银</li>
                                </ul>
                            </li>
                            <li><strong>通知亲友</strong>（第20-25分钟）：在朋友圈或让家人帮忙发消息，通知亲友手机丢失，防止骗子用你的身份骗别人。</li>
                            <li><strong>报警</strong>（第25-30分钟）：拨打110或去最近的派出所报案，拿到报案回执。后续保险理赔、银行纠纷都需要这个回执。</li>
                        </ol>
```
:::

#### 场景二：被骗了——72小时黄金处理期

发现自己被骗后，最关键是冷静。慌乱中做错误决定会导致二次损失。按以下步骤操作：

1. <strong>立即停止一切转账操作</strong>：不管骗子说什么，不要再转一分钱。"再转一笔保证金就能退回之前的钱"是经典二次诈骗话术。
2. <strong>保留所有证据</strong>：不要删聊天记录！不要删通话记录！截图保存聊天记录、转账记录、对方账号信息。这些都是报案和追回资金的关键证据。
3. <strong>立即拨打96110</strong>：这是全国反诈专线。接线员会指导你做紧急止付——如果转账时间不长（通常24小时内），银行有可能冻结对方账户拦截资金。
4. <strong>拨打110报警</strong>：带上手机、身份证、转账凭证去最近的派出所做笔录。
5. <strong>联系银行/支付平台</strong>：告知被骗情况，要求冻结涉案账户。如果是信用卡被盗刷，要求银行启动拒付流程。
6. <strong>修改所有密码</strong>：在另一台安全设备上修改你的Apple ID/品牌账号、微信、支付宝、银行App的密码，开启双重认证。

#### 场景三：手机中了病毒/木马——怎么办？

如果你发现手机出现以下症状——莫名其妙弹出广告、自动安装奇怪App、话费暴增、流量异常消耗——很可能是中了恶意软件：

- <strong>第一步：进入安全模式</strong>——安卓手机长按电源键关机，再长按电源键开机，开机震动后长按音量减键不放，直到进入安全模式（左下角会显示"安全模式"字样）。安全模式下所有第三方App被禁用，方便排查。
- <strong>第二步：卸载可疑App</strong>——在安全模式下进入设置 > 应用管理，按时间排序，找到最近安装的不认识的App卸载掉。
- <strong>第三步：安装安全App扫描</strong>——下载"腾讯手机管家"或"360手机卫士"做一次全盘扫描。
- <strong>第四步：恢复出厂设置</strong>（终极方案）——如果以上方法无效，备份重要数据后恢复出厂设置。注意：恢复出厂会删除所有数据，一定要先备份照片、通讯录等重要文件。
- <strong>iPhone基本不会中毒</strong>——iOS的沙盒机制让恶意软件很难存活。如果你的iPhone出现异常，大概率是某个App的bug或设置问题，不是病毒。恢复出厂设置能解决99%的问题。

#### 场景四：账号被盗——快速夺回控制权

1. <strong>立即修改密码</strong>：如果你还能登录账号，第一时间改密码。新密码要和旧密码完全不同。
2. <strong>踢掉其他设备</strong>：在账号安全设置里找到"登录设备管理"，把不认识的设备全部踢下线。
3. <strong>检查登录记录</strong>：查看最近7天的登录记录，如果有异地登录，说明账号确实被盗了。
4. <strong>开启双重认证</strong>：如果你还没开双重认证，现在立刻开。这是防止账号再次被盗最有效的方法。
5. <strong>检查绑定信息</strong>：检查账号绑定的手机号、邮箱有没有被改。如果被改了，用账号申诉功能找回。
6. <strong>检查支付设置</strong>：如果被盗的是微信/支付宝，检查免密支付、自动扣款有没有被篡改，银行卡有没有被添加到陌生账户。

#### 场景五：收到勒索信息——不要怕，不要付

常见的勒索套路有两种：①"我有你的不雅视频/照片，不给钱就发给你通讯录里所有人"；②"你的手机被黑客控制了，不给钱就锁死"。遇到这种情况：

- <strong>99.9%是诈骗</strong>：他们手里根本没有你的任何隐私数据。群发同样的勒索信息给几万人，总有人害怕付钱。
- <strong>不要回复，不要付钱</strong>：回复了等于告诉对方"这个号码有人用"，你会被标记为"可勒索目标"，后续骚扰更多。
- <strong>截图保存证据</strong>：然后拉黑对方。
- <strong>修改密码</strong>：如果担心，修改一下你主要账号的密码，图个安心。
- <strong>如果真的有隐私泄露风险</strong>：报警。警方有处理这类案件的经验。

#### 场景六：AI换脸/AI拟声诈骗——眼见不再为实

2024年起，AI换脸和AI拟声技术已经能让骗子在视频通话里"变成"你的家人、领导、朋友的脸和声音。"妈，我出事了，快转钱过来"——视频里的人长得、听起来都跟你儿子一模一样，但其实是假的。这是当前最难防、也最危险的诈骗手法之一。

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-exclamation-circle mr-2"></i>第一步：识别破绽——AI伪造的四个常见漏洞

{class="list-disc pl-6 mt-1 space-y-1"}
- <strong>眨眼频率异常</strong>：真人每分钟眨眼15-20次，AI换脸往往眨眼过少或节奏僵硬。
- <strong>嘴型与音频不同步</strong>：仔细看口型和听到的声音之间，会有零点几秒的错位。
- <strong>面部边缘模糊</strong>：脸的轮廓、耳朵附近、头发边缘容易出现"毛边"或闪烁。
- <strong>光影方向不一致</strong>：脸上的高光、阴影和背景的光照方向对不上，或者侧脸时五官"跟着转"得不对。
:::

::: div .info-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-lightbulb mr-2"></i>第二步：三招验证对方真假

{class="list-disc pl-6 mt-1 space-y-1"}
- <strong>要求做特定动作</strong>：让对方<strong>转头、捂脸、用手挡住嘴巴</strong>再做开合动作。AI换脸在遮挡和大角度转头时最容易"露馅"——脸会变形或跟不上动作。
- <strong>问只有对方知道的问题</strong>：编一个假问题，比如"上次咱家狗送去哪家医院看的？"——如果是骗子，他答不上来或者支支吾吾。
- <strong>回拨已知号码</strong>：挂断视频，用你通讯录里存的号码直接回拨过去。骗子控制不了真实的手机号，一拨就露馅。
:::

::: div .warning-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-shield-halved mr-2"></i>第三步：确认被骗后的报警流程

{class="list-decimal pl-6 mt-1 space-y-1"}
1. <strong>立即停止转账</strong>：再"急"也先停一下，凡是催你"快转账、别挂电话"的，几乎都是骗子。
2. <strong>保留全部证据</strong>：录屏、截图保存视频通话画面、聊天记录、对方账号、转账凭证——这些是技术鉴定的关键材料。
3. <strong>拨打96110反诈专线</strong>：告知是"AI换脸/拟声"类诈骗，接线员会启动紧急止付。
4. <strong>拨打110报警</strong>：带齐证据去派出所做笔录，特别说明使用了AI伪造技术，便于警方立案定性。
5. <strong>通知亲友</strong>：骗子可能用你的伪造视频去骗别人，提前在朋友圈或家庭群里发个提醒。
:::

#### 场景七：SIM swap攻击（SIM劫持）——你的号码被"偷"走了

这是一种很多人没听过、但危害极大的攻击。<strong>SIM swap（SIM卡劫持）</strong>指的是攻击者通过伪造你的身份信息，冒充你到营业厅补办一张新的SIM卡。一旦补办成功，你手机的信号会突然消失，而攻击者的手机插着那张新卡，能收到你所有的短信验证码——支付宝、银行、微信，全部门户大开。

::: div .info-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-lightbulb mr-2"></i>怎么发现？SIM swap的三个预警信号

{class="list-disc pl-6 mt-1 space-y-1"}
- 手机突然显示<strong>"无服务"/"无SIM卡"</strong>，但你明明没动过卡，重启也没用——这往往是被劫持的瞬间。
- 收到运营商发来的"补卡成功"或"业务办理成功"短信——但你本人没办过。
- 突然收不到验证码，但其他短信也收不到——因为短信被劫持到了攻击者的卡上。
:::

::: div .warning-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-shield-halved mr-2"></i>防护措施——把SIM卡也"上锁"

{class="list-disc pl-6 mt-1 space-y-1"}
- <strong>设置SIM卡PIN码</strong>：路径 <code class="bg-gray-100 dark:bg-gray-800 px-1 rounded">设置 &gt; 电话 &gt; SIM卡PIN码</code>。开启后，每次手机重启或换卡，都要输PIN才能用这张卡。攻击者就算拿到卡也用不了。
- <strong>开启运营商二次验证</strong>：登录中国移动/联通/电信App，找到"安全中心"或"业务办理验证"，开启<strong>非本人补卡短信提醒</strong>和<strong>业务办理二次密码验证</strong>。这样别人去补你的卡时，营业员会要求额外的身份核验。
- <strong>重要账号别只用短信验证</strong>：银行、Apple ID等高价值账号，优先用<strong>认证器App</strong>（Google Authenticator、微软Authenticator）或<strong>硬件密钥</strong>，而不是短信验证码。
- <strong>身份证复印件加水印</strong>：办理业务需要的复印件写明"仅供XX业务使用"——攻击者往往靠泄露的身份证信息冒充你。
:::

::: div .danger-box .rounded-lg .p-4 .mt-3
{class="font-semibold"}
<i class="fas fa-exclamation-circle mr-2"></i>被劫持后的应急处理——速度就是一切

{class="list-decimal pl-6 mt-1 space-y-1"}
1. <strong>立即拨打运营商客服挂失</strong>：移动10086 / 联通10010 / 电信10000，要求立即<strong>停机并冻结补卡业务</strong>，阻止攻击者继续使用你的号码。
2. <strong>用其他设备登录关键账号</strong>：用电脑或家人手机，立即修改银行、支付宝、微信、Apple ID的密码，并踢掉陌生设备。
3. <strong>冻结支付账户</strong>：支付宝95188挂失，微信安全中心冻结，银行客服冻结网银。
4. <strong>带身份证去营业厅</strong>：本人持身份证到自营厅补办新卡，恢复号码使用权。
5. <strong>报警</strong>：SIM swap已构成"侵犯公民个人信息罪"，带齐证据（停机时间记录、资金损失、补卡记录）报案。
6. <strong>全面排查</strong>：恢复号码后，逐一检查近期登录记录和资金流水，确认有没有被冒用过的痕迹。
:::

::: div .warning-box .rounded-lg .p-4 .mt-4
{class="font-semibold"}
<i class="fas fa-shield-halved mr-2"></i>预防胜于治疗——日常5件事

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 锁屏密码 + 双重认证，两个都开
2. "查找我的手机"确认开启
3. SIM卡设置PIN码（设置 > 电话 > SIM卡PIN码），丢了手机别人不能用你的卡
4. 不安装来历不明的App，不点陌生链接
5. 定期备份重要数据（照片、通讯录、聊天记录）
:::

::: div .practice-box .rounded-lg .p-4 .mt-4
{class="font-semibold"}
<i class="fas fa-hands mr-2"></i>动手：做一份属于你的"应急联系卡"

{class="list-decimal pl-6 mt-1 space-y-1"}
1. 找一张纸，写下以下号码：运营商客服（移动10086/联通10010/电信10000）、银行客服、96110反诈专线、110报警电话、家人电话。
2. 写下你的Apple ID/品牌账号的注册邮箱和备用联系方式。
3. 把这张纸放在钱包里或贴在冰箱上——不要存在手机里，因为出事时手机可能不在身边。
4. 现在就检查："查找我的手机"是否已开启，SIM卡PIN码是否已设置。
:::
